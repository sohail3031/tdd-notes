# Requirement

The `ShoppingCart` should allow a single `Product` to be added.

After adding a product:

- `getItemCount()` should return `1`.    
- `getTotal()` should return the price of the added product.

### Example

A product with:

```text
ID: 1
Name: Book
Price: 10
```

should result in:

```text
Item count = 1
Total = 10
```

---

## TDD Cycle

### 🔴 Red — Write the Test

First, write a test that describes the required behavior.

The test uses `@BeforeEach` to create a fresh `ShoppingCart` before every test.

```java
import static org.junit.jupiter.api.Assertions.assertEquals;

import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

public class ShoppingCartTest {

    private ShoppingCart shoppingCart;

    @BeforeEach
    public void setUp() {
        shoppingCart = new ShoppingCart();
    }

    @Test
    public void testStartWithEmptyCart() {
        // Arrange
        ShoppingCart cart = new ShoppingCart();

        // Act
        int itemCount = cart.getItemCount();
        int total = cart.getTotal();

        // Assert
        assertEquals(0, itemCount);
        assertEquals(0, total);
    }

    @Test
    public void testAddingASingleItemUpdatesAccordingly() {
        // Act
        shoppingCart.addItem(new Product("1", "Book", 10));

        // Assert
        assertEquals(1, shoppingCart.getItemCount());
        assertEquals(10, shoppingCart.getTotal());
    }
}
```

The new test requires three things that are not yet implemented:

1. A `Product` class.
2. An `addItem(Product product)` method.
3. `ShoppingCart` must calculate the total price of its products.

The test should initially fail because these features have not been implemented.

### 🟢 Green — Make the Test Pass

Implement the minimum functionality required to satisfy the test.

#### `Product.java`

```java
public class Product {

    private String id;
    private String name;
    private int price;

    public Product(String id, String name, int price) {
        this.id = id;
        this.name = name;
        this.price = price;
    }

    public String getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public int getPrice() {
        return price;
    }
}
```

The `Product` class stores:

- `id`
- `name`
- `price`

The corresponding getter methods allow the shopping cart to access the product information.

#### `ShoppingCart.java`

```java
import java.util.ArrayList;
import java.util.List;

public class ShoppingCart {

    private List<Product> products = new ArrayList<>();

    public int getItemCount() {
        return products.size();
    }

    public int getTotal() {
        return products.stream()
                .mapToInt(Product::getPrice)
                .sum();
    }

    public void addItem(Product product) {
        products.add(product);
    }
}
```

### How It Works

#### `products`

```java
private List<Product> products = new ArrayList<>();
```

The cart maintains a list of `Product` objects.

#### `addItem()`

```java
public void addItem(Product product) {
    products.add(product);
}
```

Adds the supplied product to the cart.

#### `getItemCount()`

```java
public int getItemCount() {
    return products.size();
}
```

Returns the number of products currently in the cart.

#### `getTotal()`

```java
public int getTotal() {
    return products.stream()
            .mapToInt(Product::getPrice)
            .sum();
}
```

Calculates the total by:

1. Creating a stream of products.
2. Extracting each product's price using `Product::getPrice`.
3. Adding all prices together using `sum()`.

For one product priced at `10`, the result is `10`.

### 🔵 Refactor

The implementation works, but there are a few small improvements we can make.

The `Product` fields can be made `final` because their values should not change after the product is created.

```java
public class Product {

    private final String id;
    private final String name;
    private final int price;

    public Product(String id, String name, int price) {
        this.id = id;
        this.name = name;
        this.price = price;
    }

    public String getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public int getPrice() {
        return price;
    }
}
```

The `products` reference can also be made `final` because the list itself does not need to be reassigned.

```java
private final List<Product> products = new ArrayList<>();
```

The refactored `ShoppingCart` becomes:

```java
import java.util.ArrayList;
import java.util.List;

public class ShoppingCart {

    private final List<Product> products = new ArrayList<>();

    public int getItemCount() {
        return products.size();
    }

    public int getTotal() {
        return products.stream()
                .mapToInt(Product::getPrice)
                .sum();
    }

    public void addItem(Product product) {
        products.add(product);
    }
}
```

The behavior remains unchanged, so all tests should continue to pass.

## Key Takeaways

- A `ShoppingCart` can maintain its products using a `List<Product>`.
- `addItem(Product product)` adds a product to the cart.
- `getItemCount()` can return the size of the product list.
- `getTotal()` can calculate the total price using a Java Stream.
- `@BeforeEach` provides a fresh `ShoppingCart` for every test.
- Making fields `private` and `final` improves encapsulation and prevents unnecessary reassignment.
- The TDD workflow remains:

**🔴 Red → 🟢 Green → 🔵 Refactor**
