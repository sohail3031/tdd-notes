# Description

Removing an item from the cart should decrease the item count and update the total price accordingly.

### Requirements

- Implement a `removeItem(String id)` method to remove one quantity of an item from the cart.
- Ensure `getItemCount()` correctly reflects the number of items after removal.
- Ensure `getTotal()` returns the updated total price after an item is removed.
- Use the product ID to identify the item being removed.

### Example

If a `Book` has a price of `10` and a quantity of `2`, removing one quantity should result in:

- Item count: `1`
- Total price: `10`

## TDD Implementation

The goal is to implement the requirement by first writing a test and then making it pass with the minimum amount of code necessary.

### 1. Write the Test

Add a test that verifies removing one quantity of an item decreases both the item count and the total price.

```java
@Test
public void testRemoveItemFromCart() {
    // Arrange
    Product product = new Product("2", "Bag", 20);

    // Act
    cart.addItem(product, 2);
    cart.removeItem("2");

    // Assert
    assertEquals(1, cart.getItemCount());
    assertEquals(20, cart.getTotal());
}
```

The test describes the expected behavior:

- Add two `Bag` items.
- Remove one item using its ID.
- The remaining quantity should be `1`.
- The updated total should be `20`.

---

## 2. Change the Data Structure

The original implementation uses a `List<CartItem>`.

```java
private List<CartItem> items = new ArrayList<>();
```

Removing an item by its ID is easier when the cart uses a `Map`, because the product ID can be used as the key.

Change the data structure to:

```java
private Map<String, CartItem> items = new HashMap<>();
```

The required imports are:

```java
import java.util.HashMap;
import java.util.Map;
```

---

## 3. Update `getItemCount()`

Because `items` is now a `Map`, use `items.values()` to access the `CartItem` objects.

```java
public int getItemCount() {
    return items.values()
            .stream()
            .mapToInt(item -> item.getQuantity())
            .sum();
}
```

This calculates the total quantity of all items in the cart.

---

## 4. Update `getTotal()`

Similarly, use `items.values()` when calculating the total price.

```java
public int getTotal() {
    return items.values()
            .stream()
            .mapToInt(item -> item.getPrice() * item.getQuantity())
            .sum();
}
```

The total is calculated as:

```text
price × quantity
```

for each item in the cart.

---

## 5. Update `addItem()`

When adding an item, use the product ID as the key.

The `merge()` method allows us to handle both cases:

- The product does not exist → add it.
- The product already exists → increase its quantity.

```java
public void addItem(Product product, int quantity) {
    items.merge(
        product.getId(),
        new CartItem(product, quantity),
        (oldItem, newItem) ->
            new CartItem(product, oldItem.getQuantity() + quantity)
    );
}
```

For example, adding a product with ID `"1"` and quantity `2`, followed by the same product with quantity `3`, results in a total quantity of `5`.

---

## 6. Implement `removeItem()`

The `computeIfPresent()` method can be used to update or remove an existing item.

```java
public void removeItem(String id) {
    items.computeIfPresent(
        id,
        (productId, item) ->
            item.getQuantity() > 1
                ? new CartItem(item, item.getQuantity() - 1)
                : null
    );
}
```

The logic is:

- If the item exists and its quantity is greater than `1`, decrease the quantity by `1`.
- If the quantity is `1`, return `null`, which removes the item from the `Map`.
- If the ID does not exist, nothing happens.

### ShoppingCart.java

```java
import java.util.HashMap;
import java.util.Map;

public class ShoppingCart {

    private Map<String, CartItem> items = new HashMap<>();

    public int getItemCount() {
        return items.values()
                .stream()
                .mapToInt(item -> item.getQuantity())
                .sum();
    }

    public int getTotal() {
        return items.values()
                .stream()
                .mapToInt(item -> item.getPrice() * item.getQuantity())
                .sum();
    }

    public void addItem(Product product) {
        addItem(product, 1);
    }

    public void addItem(Product product, int quantity) {
        items.merge(
            product.getId(),
            new CartItem(product, quantity),
            (oldItem, newItem) ->
                new CartItem(product, oldItem.getQuantity() + quantity)
        );
    }

    public void removeItem(String id) {
        items.computeIfPresent(
            id,
            (productId, item) ->
                item.getQuantity() > 1
                    ? new CartItem(item, item.getQuantity() - 1)
                    : null
        );
    }
}
```

## Key Takeaways

- A `Map<String, CartItem>` makes it easier to find and modify cart items using their product ID.
- `merge()` can be used to add a new item or update the quantity of an existing item.
- `computeIfPresent()` can update an existing map entry or remove it by returning `null`.
- Removing one quantity should update both the **item count** and the **total price**.
- In TDD, the test defines the expected behavior before the implementation is changed.
