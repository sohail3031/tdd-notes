# Overview

This requirement adds a maximum quantity limit for a single type of item in the `ShoppingCart`.

The cart should not allow the quantity of any individual item to exceed `10`. If an attempt is made to add a quantity that exceeds this limit, the operation should fail by throwing an `InvalidCartOperationException`.

The exception message should be:

```text
Maximum quantity exceeded
```

This requirement follows the **Red-Green-Refactor** cycle:

1. **Red:** Write a failing test for the quantity limit.
2. **Green:** Implement the minimum code required to make the test pass.
3. **Refactor:** Improve the implementation while keeping all tests passing.

---

# Requirement

## Description

The cart should enforce a maximum quantity limit of `10` for a single type of item.

Adding a quantity greater than the allowed limit should not be permitted.

## Requirements

- Define a maximum quantity limit of `10`.
- Validate quantities added through `addItem(Product product, int quantity)`.
- Throw an `InvalidCartOperationException` when the quantity exceeds the maximum limit.
- Use the exception message `"Maximum quantity exceeded"`.

## Expected Behavior

```text
Attempt to add an item
        ↓
Check the quantity
        ↓
Quantity ≤ 10?
   ↙           ↘
 Yes           No
  ↓             ↓
Add item    Throw exception
                ↓
     "Maximum quantity exceeded"
```

For example:

```text
Add 10 Books
      ↓
Allowed

Add 11 Books
      ↓
Not allowed
      ↓
InvalidCartOperationException
```

The test verifies two things:

1. `addItem()` throws an `InvalidCartOperationException`.
2. The exception contains the expected message.

Initially, the test fails because the cart does not enforce a maximum quantity limit and `InvalidCartOperationException` has not yet been implemented.

# Green Phase: Implement the Minimum Code

## Step 1: Create `InvalidCartOperationException`

The requirement specifies a custom exception named `InvalidCartOperationException`.

It extends `RuntimeException`, allowing it to be thrown without being explicitly declared in the method signature.

```java
package exceptions;

public class InvalidCartOperationException extends RuntimeException {

    public InvalidCartOperationException(String message) {
        super(message);
    }
}
```

---

## Step 2: Define the Maximum Quantity

Instead of using the value `10` directly throughout the code, define it as a constant.

```java
private static final int MAX_QUANTITY = 10;
```

Using a named constant makes the purpose of the value clear and makes future changes easier.

---

## Step 3: Check the Quantity Before Adding the Item

The cart must check whether adding the requested quantity would exceed `MAX_QUANTITY`.

```java
if (currentQuantity + quantity > MAX_QUANTITY) {
    throw new InvalidCartOperationException("Maximum quantity exceeded");
}
```

If the quantity is within the allowed limit, the item can be added normally.

---

# Supporting Existing Items

The final implementation also handles items that already exist in the cart.

First, the current quantity is determined:

```java
int currentQuantity = 0;

if (items.containsKey(product.getId())) {
    currentQuantity = items.get(product.getId()).getQuantity();
}
```

The new combined quantity is then validated:

```java
if (currentQuantity + quantity > MAX_QUANTITY) {
    throw new InvalidCartOperationException("Maximum quantity exceeded");
}
```

For example:

```text
Current quantity = 8
New quantity = 3

8 + 3 = 11
        ↓
11 > 10
        ↓
InvalidCartOperationException
```

If the item already exists and the new total is valid, its quantity is updated:

```java
CartItem existingItem = items.get(product.getId());

existingItem.setQuantity(currentQuantity + quantity);
```

Otherwise, a new `CartItem` is added to the cart.

## `ShoppingCart.java`

```java
import java.util.HashMap;
import java.util.Map;

import exceptions.*;

public class ShoppingCart {

    private Map<String, CartItem> items = new HashMap<>();
    private double percentageDiscount = 0.0;

    private static final double BULK_DISCOUNT_THRESHOLD = 150.0;
    private static final double BULK_DISCOUNT_PERCENTAGE = 0.10;

    private static final int MAX_QUANTITY = 10;

    public int getItemCount() {
        return items.values().stream()
                .mapToInt(CartItem::getQuantity)
                .sum();
    }

    public int getTotal() {
        int subtotal = items.values().stream()
                .mapToInt(item -> item.getPrice() * item.getQuantity())
                .sum();

        // Apply bulk discount if applicable
        if (subtotal > BULK_DISCOUNT_THRESHOLD) {
            subtotal -= (int) (subtotal * BULK_DISCOUNT_PERCENTAGE);
        }

        return (int) (subtotal * (1 - percentageDiscount / 100));
    }

    public void addItem(Product product, int quantity) {
        int currentQuantity = 0;

        if (items.containsKey(product.getId())) {
            currentQuantity = items.get(product.getId()).getQuantity();
        }

        if (currentQuantity + quantity > MAX_QUANTITY) {
            throw new InvalidCartOperationException(
                    "Maximum quantity exceeded"
            );
        }

        if (items.containsKey(product.getId())) {
            CartItem existingItem = items.get(product.getId());
            existingItem.setQuantity(currentQuantity + quantity);
        } else {
            items.put(
                    product.getId(),
                    new CartItem(product, quantity)
            );
        }
    }

    public void addItem(Product product) {
        addItem(product, 1);
    }

    public void removeItem(String id) {
        if (!items.containsKey(id)) {
            throw new ItemNotFoundException("Item not found");
        }

        CartItem item = items.get(id);

        if (item.getQuantity() > 1) {
            item.setQuantity(item.getQuantity() - 1);
        } else {
            items.remove(id);
        }
    }

    public void applyDiscount(double percentage) {
        this.percentageDiscount = percentage;
    }

    public void clear() {
        items.clear();
    }

    public void updateQuantity(String id, int quantity) {
        if (items.containsKey(id)) {
            CartItem item = items.get(id);
            item.setQuantity(quantity);
        }
    }
}
```

# How the Implementation Works

The `addItem()` method follows this process:

```text
addItem(product, quantity)
            ↓
Check whether item already exists
            ↓
Get current quantity
            ↓
Calculate:
currentQuantity + quantity
            ↓
Does total exceed 10?
        ↙           ↘
      Yes           No
       ↓             ↓
Throw exception   Does item exist?
                       ↙       ↘
                     Yes       No
                      ↓         ↓
              Update quantity  Add new CartItem
```

For a new item:

```text
Current quantity = 0
Requested quantity = 5

0 + 5 = 5
        ↓
5 ≤ 10
        ↓
Add item successfully
```

For an existing item:

```text
Current quantity = 7
Requested quantity = 2

7 + 2 = 9
        ↓
9 ≤ 10
        ↓
Update existing item quantity
```

If the limit is exceeded:

```text
Current quantity = 8
Requested quantity = 3

8 + 3 = 11
        ↓
11 > 10
        ↓
InvalidCartOperationException
```

# Key Takeaways

- A single item type cannot have a quantity greater than `10`.
- `MAX_QUANTITY` is defined as a constant instead of repeatedly using the value `10`.
- `InvalidCartOperationException` is used for invalid cart operations.
- The exception message is `"Maximum quantity exceeded"`.
- The quantity is validated before modifying the cart.
- Existing items are updated instead of automatically creating duplicate entries.
- The implementation checks the **combined quantity** of an existing item and the newly added quantity.
- The implementation follows the **Red-Green-Refactor** approach by first defining the expected behavior with a test and then adding the minimum code required to satisfy it.
