# Overview

The requirement is to prevent users from applying discount codes that are not recognized by the shopping cart.

If an invalid discount code is provided, the cart should throw a custom `InvalidDiscountCodeException` with the message:

```text
Invalid discount code
```

### Requirement

- `applyDiscountCode(code)` must validate the discount code.
- Valid codes should continue to work.
- Invalid codes should throw `InvalidDiscountCodeException`.
- The exception message must be `"Invalid discount code"`.

---

## TDD Approach

The feature follows the **Red → Green → Refactor** cycle.

### 1. Red — Write the failing test

First, write a test describing the expected behavior.

```java
// Requirement #14
@Test
public void testInvalidDiscountCode() {

    // Arrange
    Product book = new Product("1", "Book", 10);
    cart.addItem(book);

    // Act & Assert
    Exception exception = assertThrows(
        InvalidDiscountCodeException.class,
        () -> cart.applyDiscountCode("INVALID")
    );

    assertEquals("Invalid discount code", exception.getMessage());
}
```

### What the test verifies

The test checks that:

1. A product is added to the cart.
2. An invalid code `"INVALID"` is applied.
3. `InvalidDiscountCodeException` is thrown.
4. The exception contains the expected message.

Initially, this test fails because `applyDiscountCode()` does not validate the code.

---

# 2. Green — Implement the minimum code

### Create the custom exception

`InvalidDiscountCodeException.java`

```java
package exceptions;

public class InvalidDiscountCodeException extends RuntimeException {

    public InvalidDiscountCodeException(String message) {
        super(message);
    }
}
```

This follows the same pattern as the existing custom exceptions:

```java
ItemNotFoundException
InvalidCartOperationException
InvalidDiscountCodeException
```

---

## Validate the discount code

Update `applyDiscountCode()`:

```java
public void applyDiscountCode(String code) {

    if (!VALID_DISCOUNT_CODES.containsKey(code)) {
        throw new InvalidDiscountCodeException("Invalid discount code");
    }

    this.discountCode = code;
}
```

### How it works

The existing map contains the valid discount codes:

```java
private static final Map<String, Integer> VALID_DISCOUNT_CODES = new HashMap<>();

static {
    VALID_DISCOUNT_CODES.put("HOLIDAY25", 25);
}
```

The method checks:

```java
VALID_DISCOUNT_CODES.containsKey(code)
```

If the code does **not** exist:

```java
throw new InvalidDiscountCodeException("Invalid discount code");
```

If the code exists:

```java
this.discountCode = code;
```

---

# 3. Green — Test passes

For an invalid code:

```java
cart.applyDiscountCode("INVALID");
```

the map does not contain `"INVALID"`:

```text
VALID_DISCOUNT_CODES.containsKey("INVALID")
        ↓
      false
        ↓
InvalidDiscountCodeException
```

For a valid code:

```java
cart.applyDiscountCode("HOLIDAY25");
```

the map contains the code:

```text
VALID_DISCOUNT_CODES.containsKey("HOLIDAY25")
        ↓
       true
        ↓
this.discountCode = "HOLIDAY25"
```
