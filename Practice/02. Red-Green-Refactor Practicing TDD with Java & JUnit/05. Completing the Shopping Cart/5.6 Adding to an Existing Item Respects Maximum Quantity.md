# 🎯 Requirement

When adding more units to an item that already exists in the cart:

- The existing quantity should be increased.    
- The **combined quantity must not exceed 10**.
- If the combined quantity exceeds `MAX_QUANTITY`, throw `InvalidCartOperationException`.
- The exception message must be `"Maximum quantity exceeded"`.

### Example

```text
Existing quantity = 8
Adding quantity    = 3
New quantity       = 11 ❌
```

Therefore:

```text
InvalidCartOperationException
"Maximum quantity exceeded"
```

---

# 1. Write the Test First

The test should specifically verify the **existing-item scenario**.

Your current test:

```java
cart.addItem(book, 11);
```

only tests adding **11 units to a new item**, which is already covered by Requirement #11.

It does **not** test Requirement #16.

### Correct test

```java
// Requirement #16
@Test
public void testAddingExistingItemExceedsMaximumQuantity() {
    // Arrange
    Product book = new Product("1", "Book", 200);
    cart.addItem(book, 8);

    // Act & Assert
    Exception exception = assertThrows(InvalidCartOperationException.class, () -> {
        cart.addItem(book, 3);
    });

    assertEquals("Maximum quantity exceeded", exception.getMessage());
}
```

### Why this is the correct test

The important part is:

```java
cart.addItem(book, 8);
```

followed by:

```java
cart.addItem(book, 3);
```

So the test verifies:

```text
8 + 3 = 11
```

Since `11 > 10`, the operation must fail.

---

# 2. Red Phase 🔴

With the starter implementation:

```java
CartItem existingItem = items.get(product.getId());

if (existingItem != null) {
    existingItem.setQuantity(existingItem.getQuantity() + quantity);
}
```

the cart would simply do:

```text
8 + 3 = 11
```

and allow the invalid quantity.

Therefore, the new test fails.

This is exactly what we want in the **Red** phase.

---

# 3. Minimal Implementation

The smallest change is to check the **combined quantity** before updating it.

Change:

```java
if (existingItem != null) {
    existingItem.setQuantity(existingItem.getQuantity() + quantity);
}
```

to:

```java
if (existingItem != null) {
    if (existingItem.getQuantity() + quantity > MAX_QUANTITY) {
        throw new InvalidCartOperationException("Maximum quantity exceeded");
    }

    existingItem.setQuantity(existingItem.getQuantity() + quantity);
}
```

For a new item, keep the existing check:

```java
if (quantity > MAX_QUANTITY) {
    throw new InvalidCartOperationException("Maximum quantity exceeded");
}
```

---

# 4. Final `addItem()` Method

```java
public void addItem(Product product, int quantity) {
    CartItem existingItem = items.get(product.getId());

    if (existingItem != null) {
        if (existingItem.getQuantity() + quantity > MAX_QUANTITY) {
            throw new InvalidCartOperationException("Maximum quantity exceeded");
        }

        existingItem.setQuantity(existingItem.getQuantity() + quantity);
    } else {
        if (quantity > MAX_QUANTITY) {
            throw new InvalidCartOperationException("Maximum quantity exceeded");
        }

        items.put(product.getId(), new CartItem(product, quantity));
    }
}
```

Now:

```java
cart.addItem(book, 8);
```

Then:

```java

```

checks:

```java

```


```java
throw new InvalidCartOperationException("Maximum quantity exceeded");
```

The test passes.

# 6. Important Difference Between Requirement #11 and #16

This distinction is important for your TDD notes.

### Requirement #11 — New item

```java
cart.addItem(book, 11);
```

The requested quantity itself exceeds the limit:

```text
11 > 10
```

### Requirement #16 — Existing item

```java
cart.addItem(book, 8);
cart.addItem(book, 3);
```

Each individual request is valid:

```text
8 <= 10
3 <= 10
```

But the **combined quantity** is invalid:

```text
8 + 3 = 11
11 > 10
```

Therefore, checking only:

```java
quantity > MAX_QUANTITY
```

is **not sufficient**.

You must check:

```java
existingQuantity + quantity > MAX_QUANTITY
```

### New item

Check the requested quantity:
