# Overview

The requirement is to ensure that adding the **same product again** increases its quantity instead of creating a duplicate cart entry.

For example:

```text
Add Book (ID: 1, Price: $100, Quantity: 1)
Add Book (ID: 1, Price: $100, Quantity: 1)

Result:
Quantity = 2
Total = $180
```

The total is `$180` because the subtotal becomes `$200`, which triggers the existing **10% bulk discount**.

---

# TDD Approach

We follow the **Red → Green → Refactor** cycle.

## 1. Red — Write the test

The test should verify two important behaviors:

1. The existing item's quantity increases.
2. The total reflects the cumulative quantity.

A better test for the requirement is:

```java
// Requirement #15
@Test
public void testAddExistingItem() {

    // Arrange
    Product book = new Product("1", "Book", 100);
    cart.addItem(book, 1);

    // Act
    cart.addItem(book, 1);

    // Assert
    assertEquals(2, cart.getItemCount());
    assertEquals(2, cart.getItem("1").getQuantity());
    assertEquals(180, cart.getTotal());
}
```

### Why add the `getItem()` assertion?

Your current test checks:

```java
assertEquals(2, cart.getItemCount());
assertEquals(180, cart.getTotal());
```

Those verify the overall cart behavior, but the requirement specifically says:

> Ensure `getItem(id)` returns the updated quantity.

Therefore, this assertion is important:

```java
assertEquals(2, cart.getItem("1").getQuantity());
```

# 2. Red — Why does the original implementation fail?

The original implementation does this:

```java
items.put(product.getId(), new CartItem(product, quantity));
```

Suppose we execute:

```java
cart.addItem(book, 1);
cart.addItem(book, 1);
```

The second call simply replaces the existing `CartItem`.

Conceptually:

```text
First add:
"1" → Book, quantity 1

Second add:
"1" → Book, quantity 1
```

The quantity remains:

```text
1
```

instead of:

```text
2
```

# Important Correction: Maximum Quantity

Your current implementation checks:

```java
if (quantity > MAX_QUANTITY)
```

when adding an existing item.

That checks only the **new quantity being added**, not the resulting quantity.

For example:

```java
cart.addItem(book, 8);
cart.addItem(book, 5);
```

Your current code allows it because:

```text
5 <= 10
```

But the resulting quantity is:

```text
8 + 5 = 13
```

which exceeds the maximum quantity of `10`.

The correct check is:

```java
if (newQuantity > MAX_QUANTITY) {
    throw new InvalidCartOperationException("Maximum quantity exceeded");
}
```

---

# Recommended Final `addItem()`

A clean implementation is:

```java
public void addItem(Product product, int quantity) {

    if (items.containsKey(product.getId())) {

        CartItem cartItem = items.get(product.getId());

        int newQuantity = cartItem.getQuantity() + quantity;

        if (newQuantity > MAX_QUANTITY) {
            throw new InvalidCartOperationException("Maximum quantity exceeded");
        }

        cartItem.setQuantity(newQuantity);

    } else {

        if (quantity > MAX_QUANTITY) {
            throw new InvalidCartOperationException("Maximum quantity exceeded");
        }

        items.put(
            product.getId(),
            new CartItem(product, quantity)
        );
    }
}
```

# How It Works

### First addition

```java
cart.addItem(book, 1);
```

The item doesn't exist:

```text
items.containsKey("1") → false
```

So:

```text
"1" → Book, quantity 1
```

---

### Second addition

```java
cart.addItem(book, 1);
```

Now:

```text
items.containsKey("1") → true
```

The existing item is retrieved:

```java
CartItem cartItem = items.get("1");
```

Current quantity:

```text
1
```

New quantity:

```text
1 + 1 = 2
```

Then:

```java
cartItem.setQuantity(2);
```

The map still contains only **one item**:

```text
"1" → Book, quantity 2
```

There is no duplicate `CartItem`.

---

# Total Calculation

The existing `getTotal()` already calculates the total using quantity:

```java
int subtotal = items.values()
    .stream()
    .mapToInt(item -> item.getPrice() * item.getQuantity())
    .sum();
```

For:

```text
Book price = $100
Quantity = 2
```

the subtotal becomes:

```text
100 × 2 = $200
```

Because `$200 > $150`, the existing bulk discount applies:

```text
$200 - 10% = $180
```

Therefore:

```java
assertEquals(180, cart.getTotal());
```

passes without needing to modify `getTotal()`.
