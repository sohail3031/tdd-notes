# Overview

This requirement adds the ability to retrieve an item's details from the `ShoppingCart` using its unique ID.

The new `getItem(String id)` method should return the corresponding `CartItem` stored in the cart. The returned object contains both the original product information and the quantity currently stored in the cart.

After retrieving an item, we should be able to access:

- Item ID    
- Item name
- Item price
- Item quantity

This feature follows the **Red-Green-Refactor** cycle:

1. **Red:** Write a failing test for retrieving an item by ID.
2. **Green:** Implement the minimum code required to make the test pass.
3. **Refactor:** Improve the code if necessary while keeping all tests passing.

---

# Requirement

## Description

When an item is added to the cart, it should be possible to retrieve that item's details using its ID.

The retrieved item should include both the product details and the quantity stored in the cart.

## Requirements

- Implement a `getItem(String id)` method.
- Retrieve the item using its unique ID.
- Return the corresponding `CartItem`.
- Ensure the returned item contains the correct:
    - ID
    - Name
    - Price
    - Quantity

## Expected Behavior

```text
Create Product
      ↓
Add Product to Cart
      ↓
Store CartItem in Map using Product ID
      ↓
Call getItem(id)
      ↓
Retrieve CartItem
      ↓
Access Product Details and Quantity
```

For example:

```text
Product:
ID       = "1"
Name     = "Book"
Price    = 10
Quantity = 2

Call:
getItem("1")

Result:
ID       = "1"
Name     = "Book"
Price    = 10
Quantity = 2
```

# Green Phase: Implement the Minimum Code

The cart already stores items in a `Map<String, CartItem>`:

```java
private Map<String, CartItem> items = new HashMap<>();
```

The product ID is used as the key:

```text
Key          Value
────────────────────────────
"1"    →     CartItem
"2"    →     CartItem
"3"    →     CartItem
```

Since a `Map` provides the `get()` method, the minimum implementation is:

```java
public CartItem getItem(String id) {
    return items.get(id);
}
```

The `id` is used to look up the corresponding `CartItem` in the `items` map.

No additional calculations or modifications are required.

# Why `CartItem` Contains All Required Details

`CartItem` extends `Product`:

```java
public class CartItem extends Product {
```

Therefore, a `CartItem` inherits the following methods from `Product`:

```java
getId()
getName()
getPrice()
```

It also contains its own quantity-related methods:

```java
getQuantity()
setQuantity()
```

As a result, the retrieved `CartItem` provides both product information and cart-specific quantity information.

```text
Product
├── id
├── name
└── price
        ▲
        │ extends
        │
CartItem
├── inherited: id
├── inherited: name
├── inherited: price
└── quantity
```

# Final Implementation

## ShoppingCart.java

The new method added for Requirement #12 is:

```java
public CartItem getItem(String id) {
    return items.get(id);
}
```

The complete `ShoppingCart` class is:

```java
import java.util.HashMap;
import java.util.Map;

import exceptions.*;

public class ShoppingCart {

    private Map<String, CartItem> items = new HashMap<>();
    private double percentageDiscount = 0.0;

    private static final double BULK_DISCOUNT_THRESHOLD = 150.0;
    private static final double BULK_DISCOUNT_PERCENTAGE = 0.10;

    private static final double MAX_QUANTITY = 10;

    public int getItemCount() {
        return items.values()
                .stream()
                .mapToInt(CartItem::getQuantity)
                .sum();
    }

    public int getTotal() {
        int subtotal = items.values()
                .stream()
                .mapToInt(item -> item.getPrice() * item.getQuantity())
                .sum();

        // Apply bulk discount if applicable
        if (subtotal > BULK_DISCOUNT_THRESHOLD) {
            subtotal -= (int) (subtotal * BULK_DISCOUNT_PERCENTAGE);
        }

        return (int) (subtotal * (1 - percentageDiscount / 100));
    }

    public void addItem(Product product, int quantity) {
        if (quantity > MAX_QUANTITY) {
            throw new InvalidCartOperationException(
                    "Maximum quantity exceeded"
            );
        }

        items.put(
                product.getId(),
                new CartItem(product, quantity)
        );
    }

    public void addItem(Product product) {
        addItem(product, 1);
    }

    public void removeItem(String id) {
        if (!items.containsKey(id)) {
            throw new ItemNotFoundException("Item not found");
        }

        CartItem item = items.get(id);

        if (item.getQuantity() > 1) {
            item.setQuantity(item.getQuantity() - 1);
        } else {
            items.remove(id);
        }
    }

    public void applyDiscount(double percentage) {
        this.percentageDiscount = percentage;
    }

    public void clear() {
        items.clear();
    }

    public void updateQuantity(String id, int quantity) {
        if (items.containsKey(id)) {
            CartItem item = items.get(id);
            item.setQuantity(quantity);
        }
    }

    public CartItem getItem(String id) {
        return items.get(id);
    }
}
```

# How `getItem()` Works

The cart stores items using their IDs as keys:

```java
private Map<String, CartItem> items = new HashMap<>();
```

When a product is added:

```java
cart.addItem(book, 2);
```

the internal map conceptually contains:

```text
items
│
└── "1"
     │
     ▼
   CartItem
   ├── ID: "1"
   ├── Name: "Book"
   ├── Price: 10
   └── Quantity: 2
```

Calling:

```java
CartItem cartItem = cart.getItem("1");
```

is equivalent to retrieving the value associated with the key `"1"`:

```java
return items.get("1");
```

The returned `CartItem` can then be used to access all item details.

# Key Takeaways

- `getItem(String id)` retrieves a cart item using its unique ID.
- The `items` map uses the product ID as its key.
- `Map.get(id)` provides the minimum implementation needed for this requirement.
- `CartItem` contains both product information and quantity information.
- Because `CartItem` extends `Product`, it inherits `getId()`, `getName()`, and `getPrice()`.
- The `getItem()` method does not modify the cart; it only retrieves an existing item.

> **Tip:** When testing object retrieval, verify all important properties rather than only checking that the returned object is not `null`. This provides stronger evidence that the correct object was retrieved.
