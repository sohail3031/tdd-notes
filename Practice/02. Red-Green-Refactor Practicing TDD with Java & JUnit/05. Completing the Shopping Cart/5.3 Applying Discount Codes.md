# Objective

Implement support for applying valid discount codes to the shopping cart.

A valid discount code should apply its corresponding discount percentage to the cart total.

---

## Requirement

The `ShoppingCart` should:

- Provide an `applyDiscountCode(String code)` method.
- Support valid discount codes.
- Support the `HOLIDAY25` discount code.
- Apply a `25%` discount when `HOLIDAY25` is used.
- Update the cart total after applying the discount.

### Example

If the cart contains:

| Product | Price | Quantity |
|---|---:|---:|
| Book | 50 | 2 |

The subtotal is:

```text
50 × 2 = 100
````

After applying:

```text
HOLIDAY25
```

The total should be:

```text
100 - 25% = 75
```

# TDD Cycle

## 1. Red Phase

First, write a failing test that describes the required behavior.

### Test

```java
// Requirement #13
@Test
public void testApplyingValidDiscountCodes() {
    // Arrange
    Product book = new Product("1", "Book", 50);
    cart.addItem(book, 2);

    // Act
    cart.applyDiscountCode("HOLIDAY25");
    int itemCount = cart.getItemCount();
    int total = cart.getTotal();

    // Assert
    assertEquals(2, itemCount);
    assertEquals(75, total);
}
```

### What the Test Verifies

The test verifies that:

1. A valid discount code can be applied.
2. `HOLIDAY25` represents a `25%` discount.
3. The item quantity remains unchanged.
4. The total is correctly updated after applying the discount.

### Initial Result

The test initially fails because:

```java
applyDiscountCode(String code)
```

has not yet been implemented.

This is the **Red** phase of TDD.

## 2. Green Phase

Implement the minimum code necessary to make the test pass.

### Create a Discount Code Map

```java
private Map<String, Double> discounts = Map.of("HOLIDAY25", 25.0);
```

This map stores discount codes and their corresponding discount percentages.

|Discount Code|Discount|
|---|--:|
|`HOLIDAY25`|`25%`|

### Implement `applyDiscountCode()`

```java
public void applyDiscountCode(String code) {
    percentageDiscount = discounts.get(code);
}
```

When the code is applied:

```java
cart.applyDiscountCode("HOLIDAY25");
```

the following value is retrieved:

```text
25.0
```

and assigned to:

```java
percentageDiscount
```

The existing `getTotal()` method already uses `percentageDiscount`:

```java
return (int) (subtotal * (1 - percentageDiscount / 100));
```

For a subtotal of `100`:

```text
100 × (1 - 25 / 100)
= 100 × 0.75
= 75
```

The test now passes.

This is the **Green** phase.

# Final Implementation

## ShoppingCart.java

### Add the Discount Code Map

```java
private Map<String, Double> discounts = Map.of("HOLIDAY25", 25.0);
```

### Add the `applyDiscountCode()` Method

```java
public void applyDiscountCode(String code) {
    percentageDiscount = discounts.get(code);
}
```

---

## Key Concept: Reusing Existing Behavior

The implementation does not need to modify the discount calculation in `getTotal()` because that method already supports percentage-based discounts.

The new functionality simply converts a discount code into a discount percentage.

```text
HOLIDAY25
     ↓
25.0
     ↓
percentageDiscount
     ↓
getTotal()
     ↓
75
```

---

## Important Note

The current implementation works for valid discount codes such as:

```java
"HOLIDAY25"
```

However, an invalid code would cause:

```java
discounts.get(code)
```

to return `null`.

Because `percentageDiscount` is a primitive `double`, assigning `null` would result in an error due to unboxing.

Handling invalid discount codes is addressed in the next requirement.

## Final Takeaways

- A `Map` can be used to associate discount codes with discount percentages.
- `Map.of()` creates an immutable map for fixed discount codes.
- Existing functionality can often be reused instead of modifying multiple methods.
- The test verifies both the application of the discount and preservation of the item quantity.
- TDD encourages implementing only the minimum functionality needed to make the current test pass.
