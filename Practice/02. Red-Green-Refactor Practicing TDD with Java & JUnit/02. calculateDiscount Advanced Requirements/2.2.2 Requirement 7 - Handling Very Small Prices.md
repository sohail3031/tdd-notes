### Requirement

The `calculateDiscount()` function must ensure that the final price does not fall below the minimum value of **`0.01`** after the discount is applied and the result is rounded.

```java
double discountPercentage = 1.0;
```

The calculated price is:

```text
0.001 × (1 - 1 / 100)

```

After rounding to two decimal places, this would normally become:

```text
0.00
```

However, the requirement states that the final amount must not be below:

```text
0.01
```

# 🟢 Green Phase

The existing `roundToCents()` method is the appropriate place to implement this requirement because it already handles rounding.

### `DiscountCalculator.java`

```java
import java.lang.Math;

public class DiscountCalculator {

    private void validatePrice(double price) {
        if (price < 0) {
            throw new IllegalArgumentException("Price cannot be negative");
        }
    }

    private void validateDiscountPercentage(double discountPercentage) {
        if (discountPercentage > 100) {
            throw new IllegalArgumentException("Discount percentage cannot be > 100%");
        }

        if (discountPercentage < 0) {
            throw new IllegalArgumentException("Discount cannot be negative");
        }
    }

    private double roundToCents(double amount) {
        double result = Math.round(amount * 100.0) / 100.0;

        if (result < 0.01) {
            return 0.01;
        }

        return result;
    }

    public double calculateDiscount(double price, double discountPercentage) {
        validatePrice(price);
        validateDiscountPercentage(discountPercentage);

        double discountMultiplier = 1 - (discountPercentage / 100);
        return roundToCents(price * discountMultiplier);
    }
}
```

### What Changed?

We modified only `roundToCents()`:

```java
double result = Math.round(amount * 100.0) / 100.0;

if (result < 0.01) {
    return 0.01;
}
```

This ensures that any rounded result below `$0.01` is replaced with `$0.01`.

```java
@Test
public void testCalculateDiscountHandlesVerySmallPricesCorrectly() {

    double originalPrice = 0.001;
    double discountPercentage = 1.0;
    double expectedDiscountedPrice = 0.01;

            calculator.calculateDiscount(
                    originalPrice,
                    discountPercentage
            );

    // Assert
    assertEquals(
            expectedDiscountedPrice,
            result,
            0.001
    );
}
```
