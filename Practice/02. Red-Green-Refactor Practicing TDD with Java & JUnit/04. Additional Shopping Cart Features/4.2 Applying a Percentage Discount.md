# Overview

This requirement adds support for applying a percentage discount to the `ShoppingCart`.

The discount should affect the value returned by `getTotal()` while leaving the items and their quantities unchanged.

Following the **Red-Green-Refactor** cycle:

1. Write a test describing the expected behavior.    
2. Run the test and verify that it fails.
3. Implement the minimum amount of code required to make the test pass.
4. Refactor the code if necessary while ensuring all tests continue to pass.

---

## Requirement

### Description

Applying a percentage discount should adjust the total price of the items in the cart accordingly.

### Requirements

- Implement an `applyDiscount(double percentage)` method.
- Store the discount information in the `ShoppingCart`.
- Update `getTotal()` to return the discounted total.
- The discount should be applied to the total value of all items in the cart.

### Example

Applying a `10%` discount to a cart with a total of `100` should result in a new total of `90`.

```text
Original total: 100
Discount: 10%
Final total: 90
```

# Green Phase: Implement the Minimum Code

## Add a Price Multiplier

A `priceMultiplier` field can be used to represent the percentage of the original price that should be charged.

The default value is `1.0`, meaning no discount is applied.

```java
private double priceMultiplier = 1.0;
```

Examples:

|Discount|Price Multiplier|
|---|--:|
|`0%`|`1.0`|
|`10%`|`0.9`|
|`20%`|`0.8`|
|`50%`|`0.5`|

---

## Update `getTotal()`

First, calculate the subtotal of all items.

```java
int subtotal = items.values()
        .stream()
        .mapToInt(item -> item.getPrice() * item.getQuantity())
        .sum();
```

Then apply the `priceMultiplier`.

```java
return (int) (subtotal * priceMultiplier);
```

The complete implementation is:

```java
public int getTotal() {
    int subtotal = items.values()
            .stream()
            .mapToInt(item -> item.getPrice() * item.getQuantity())
            .sum();

    return (int) (subtotal * priceMultiplier);
}
```

---

## Implement `applyDiscount()`

Convert the discount percentage into a decimal and subtract it from `1.0`.

```java
public void applyDiscount(double percentage) {
    this.priceMultiplier = 1.0 - (percentage / 100.0);
}
```

For a `10%` discount:

```text
percentage = 10

percentage / 100.0 = 0.10

priceMultiplier = 1.0 - 0.10

priceMultiplier = 0.90
```

The final total is therefore:

```text
100 × 0.90 = 90
```

## ShoppingCart.java

```java
import java.util.HashMap;
import java.util.Map;

import exceptions.ItemNotFoundException;

public class ShoppingCart {

    private Map<String, CartItem> items = new HashMap<>();

    // Default multiplier is 1.0, meaning no discount is applied.
    private double priceMultiplier = 1.0;

    public int getItemCount() {
        return items.values()
                .stream()
                .mapToInt(CartItem::getQuantity)
                .sum();
    }

    public int getTotal() {
        // Calculate the total before applying the discount.
        int subtotal = items.values()
                .stream()
                .mapToInt(item -> item.getPrice() * item.getQuantity())
                .sum();

        // Apply the discount multiplier.
        return (int) (subtotal * priceMultiplier);
    }

    public void addItem(Product product, int quantity) {
        items.put(product.getId(), new CartItem(product, quantity));
    }

    public void addItem(Product product) {
        addItem(product, 1);
    }

    public void removeItem(String id) {
        if (!items.containsKey(id)) {
            throw new ItemNotFoundException("Item not found");
        }

        CartItem item = items.get(id);

        if (item.getQuantity() > 1) {
            item.setQuantity(item.getQuantity() - 1);
        } else {
            items.remove(id);
        }
    }

    public void applyDiscount(double percentage) {
        this.priceMultiplier = 1.0 - (percentage / 100.0);
    }
}
```

# Key Takeaways

- The discount is stored as a `priceMultiplier`.
    
- A default multiplier of `1.0` means that no discount is applied.
    
- A `10%` discount results in a multiplier of `0.90`.
    
- The discount is applied to the cart's subtotal when `getTotal()` is called.
    
- The discount does not modify individual product prices or quantities.
    
- The implementation adds only the functionality required to make the new test pass.
    

> [!note]  
> The current implementation casts the discounted value to `int`, which truncates any decimal portion. This is sufficient for the current requirement because the test uses a total and discount that produce a whole number. Handling decimal currency values or rounding behavior may require additional requirements and tests.
