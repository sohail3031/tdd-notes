# Overview

This requirement adds the ability to remove all items from the `ShoppingCart`.

The `clear()` method should empty the cart completely. After clearing the cart:

- `getItemCount()` should return `0`.    
- `getTotal()` should return `0`.

This feature follows the **Red-Green-Refactor** cycle:

1. **Red:** Write a failing test.
2. **Green:** Implement the minimum code required to make the test pass.
3. **Refactor:** Improve the code if necessary while keeping all tests passing.

---

## Requirement

### Description

The cart should be able to remove all items, resetting both the item count and total price to zero.

### Requirements

- Implement a `clear()` method.
- Remove all items from the cart.
- Ensure `getItemCount()` returns `0` after clearing.
- Ensure `getTotal()` returns `0` after clearing.

### Expected Behavior

```text
Cart contains items
        ↓
Call clear()
        ↓
All items are removed
        ↓
Item count = 0
Total = 0
```

For example:

```text
Before clear():
Item count = 3
Total = 50

After clear():
Item count = 0
Total = 0
```

A meaningful test should first add items to the cart, then clear it. Otherwise, testing `clear()` on an already empty cart would not fully verify the requirement.

```text

        ↓
Cart contains products
        ↓
Call clear()
        ↓
All entries are removed from the Map
        ↓
Item count = 0
Total = 0
```

Initially, the test fails because the `clear()` method has not yet been implemented.

# Green Phase: Implement the Minimum Code

The cart stores its items in a `Map<String, CartItem>`.

```java
private Map<String, CartItem> items = new HashMap<>();
```

The `Map` interface provides the `clear()` method, which removes all key-value pairs from the map.

Therefore, the minimum implementation is:

```java
public void clear() {
    items.clear();
}
```

After calling `items.clear()`:

- `items` contains no `CartItem` objects.
- `getItemCount()` returns `0`.
- The subtotal calculated by `getTotal()` is `0`.
- Therefore, `getTotal()` also returns `0`.

No changes are required to `getItemCount()` or `getTotal()`.

# Final Implementation

## ShoppingCart.java

```java
import java.util.HashMap;
import java.util.Map;

import exceptions.ItemNotFoundException;

public class ShoppingCart {

    private Map<String, CartItem> items = new HashMap<>();
    private double percentageDiscount = 0.0;

    private static final double BULK_DISCOUNT_THRESHOLD = 150.0;
    private static final double BULK_DISCOUNT_PERCENTAGE = 0.10;

    public int getItemCount() {
        return items.values()
                .stream()
                .mapToInt(CartItem::getQuantity)
                .sum();
    }

    public int getTotal() {
        int subtotal = items.values()
                .stream()
                .mapToInt(item -> item.getPrice() * item.getQuantity())
                .sum();

        // Apply the bulk discount if applicable
        if (subtotal > BULK_DISCOUNT_THRESHOLD) {
            subtotal -= (int) (subtotal * BULK_DISCOUNT_PERCENTAGE);
        }

        return (int) (subtotal * (1 - percentageDiscount / 100));
    }

    public void addItem(Product product, int quantity) {
        items.put(product.getId(), new CartItem(product, quantity));
    }

    public void addItem(Product product) {
        addItem(product, 1);
    }

    public void removeItem(String id) {
        if (!items.containsKey(id)) {
            throw new ItemNotFoundException("Item not found");
        }

        CartItem item = items.get(id);

        if (item.getQuantity() > 1) {
            item.setQuantity(item.getQuantity() - 1);
        } else {
            items.remove(id);
        }
    }

    public void applyDiscount(double percentage) {
        this.percentageDiscount = percentage;
    }

    public void clear() {
        items.clear();
    }
}
```

# Why `items.clear()` Is Enough

The cart stores all products in the following collection:

```java
private Map<String, CartItem> items = new HashMap<>();
```

Calling:

```java
items.clear();
```

removes every entry from the map.

Before clearing:

```text
items
├── "1" → Book
└── "2" → Pen
```

After clearing:

```text
items
└── empty
```

Since both `getItemCount()` and `getTotal()` calculate their values from `items`, they automatically return `0` when the map is empty.

---

# Key Takeaways

- `clear()` removes all items from the cart.
- `Map.clear()` provides the minimum implementation required for this feature.
- After clearing the cart, `getItemCount()` returns `0`.
- After clearing the cart, `getTotal()` returns `0`.
- Existing calculation methods do not need to be modified because they already work correctly with an empty collection.

> [!tip]  
> When writing a test for a clearing operation, add data before calling `clear()`. Testing `clear()` on an already empty collection provides weaker evidence because the expected result would be the same even if the method did nothing.
