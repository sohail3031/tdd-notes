# Overview

This requirement adds the ability to update the quantity of an existing item in the `ShoppingCart`.

The `updateQuantity()` method should change the quantity of a specific item. After updating the quantity:

- `getItemCount()` should return the updated item count.
- `getTotal()` should return the updated total price.
- An `ItemNotFoundException` should be thrown if the item does not exist.

This feature follows the **Red-Green-Refactor** cycle:

1. **Red:** Write a failing test.
2. **Green:** Implement the minimum code required to make the test pass.
3. **Refactor:** Improve the code if necessary while keeping all tests passing.

---

## Requirement

### Description

When the quantity of an item in the cart is changed, both the item count and total price should accurately reflect the new quantity.

### Requirements

- Implement an `updateQuantity(String id, int quantity)` method.
- Update the quantity of the specified item.
- Ensure `getItemCount()` returns the correct total item count after the quantity is updated.
- Ensure `getTotal()` returns the correct total price after the quantity is updated.
- Throw `ItemNotFoundException` if the specified item does not exist.

### Expected Behavior

```text
Cart contains an item
        ↓
Update the item's quantity
        ↓
Item quantity is changed
        ↓
getItemCount() reflects the new quantity
        ↓
getTotal() reflects the new quantity
```

For example:

```text
Before update:
Item: Book
Price: 10
Quantity: 2

Item count = 2
Total = 20

        ↓
updateQuantity("1", 3)
        ↓

After update:
Item: Book
Price: 10
Quantity: 3

Item count = 3
Total = 30
```

# Green Phase: Implement the Minimum Code

The cart stores its items in a `Map`:

```java
private Map<String, CartItem> items = new HashMap<>();
```

The `CartItem` class already provides a `setQuantity()` method:

```java
public void setQuantity(int quantity) {
    this.quantity = quantity;
}
```

Therefore, the minimum implementation is to:

1. Check whether the item exists.
2. Retrieve the corresponding `CartItem`.
3. Update its quantity using `setQuantity()`.

```java
public void updateQuantity(String id, int quantity) {
    if (!items.containsKey(id)) {
        throw new ItemNotFoundException("Item not found");
    }

    CartItem cartItem = items.get(id);
    cartItem.setQuantity(quantity);
}
```

After the quantity is updated, the existing `getItemCount()` and `getTotal()` methods automatically use the new quantity.

No changes are required to those methods.

# Handling a Non-Existent Item

If the specified item ID does not exist, `updateQuantity()` should throw an `ItemNotFoundException`.

For example:

```java
cart.updateQuantity("999", 3);
```

The method handles this situation with:

```java
if (!items.containsKey(id)) {
    throw new ItemNotFoundException("Item not found");
}
```

This is consistent with the existing behavior of `removeItem()`.

# Final Implementation

## ShoppingCart.java

```java
import java.util.HashMap;
import java.util.Map;

import exceptions.ItemNotFoundException;

public class ShoppingCart {

    private Map<String, CartItem> items = new HashMap<>();
    private double percentageDiscount = 0.0;

    private static final double BULK_DISCOUNT_THRESHOLD = 150.0;
    private static final double BULK_DISCOUNT_PERCENTAGE = 0.10;

    public int getItemCount() {
        return items.values().stream()
                .mapToInt(CartItem::getQuantity)
                .sum();
    }

    public int getTotal() {
        int subtotal = items.values().stream()
                .mapToInt(item -> item.getPrice() * item.getQuantity())
                .sum();

        // Apply bulk discount if applicable
        if (subtotal > BULK_DISCOUNT_THRESHOLD) {
            subtotal -= (int) (subtotal * BULK_DISCOUNT_PERCENTAGE);
        }

        return (int) (subtotal * (1 - percentageDiscount / 100));
    }

    public void addItem(Product product, int quantity) {
        items.put(product.getId(), new CartItem(product, quantity));
    }

    public void addItem(Product product) {
        addItem(product, 1);
    }

    public void removeItem(String id) {
        if (!items.containsKey(id)) {
            throw new ItemNotFoundException("Item not found");
        }

        CartItem item = items.get(id);

        if (item.getQuantity() > 1) {
            item.setQuantity(item.getQuantity() - 1);
        } else {
            items.remove(id);
        }
    }

    public void applyDiscount(double percentage) {
        this.percentageDiscount = percentage;
    }

    public void clear() {
        items.clear();
    }

    public void updateQuantity(String id, int quantity) {
        if (!items.containsKey(id)) {
            throw new ItemNotFoundException("Item not found");
        }

        CartItem cartItem = items.get(id);
        cartItem.setQuantity(quantity);
    }
}
```

# Why `getItemCount()` and `getTotal()` Do Not Need Changes

`getItemCount()` calculates the total quantity from the `CartItem` objects:

```java
return items.values().stream()
        .mapToInt(CartItem::getQuantity)
        .sum();
```

`getTotal()` calculates the price using the current quantity:

```java
return items.values().stream()
        .mapToInt(item -> item.getPrice() * item.getQuantity())
        .sum();
```

Because `updateQuantity()` changes the quantity stored in the `CartItem`, both methods automatically use the updated value.

For example:

```text
Price = 50
Quantity = 2
        ↓
Total = 100

        ↓
updateQuantity("1", 3)

        ↓

Price = 50
Quantity = 3
        ↓
Total = 150
```

# Key Takeaways

- `updateQuantity()` changes the quantity of an existing cart item.
- `CartItem.setQuantity()` can be reused to update the quantity.
- `getItemCount()` automatically reflects the new quantity.
- `getTotal()` automatically reflects the new quantity.
- `ItemNotFoundException` is thrown when the item does not exist.
- Only the minimum production code required for the feature is added.
- Existing calculation methods do not need to be modified because they already use the current `CartItem` quantity.
