# Overview

This requirement adds an automatic bulk discount to the `ShoppingCart`.

When the cart's subtotal exceeds `$150`, a `10%` discount should automatically be applied. The discounted amount should be returned by `getTotal()`.

The feature should be implemented using the **Red-Green-Refactor** cycle:

1. Write a test describing the expected behavior.    
2. Run the test and verify that it fails.
3. Implement the minimum amount of code required to make the test pass.
4. Refactor the implementation if necessary while keeping all tests passing.

---

## Requirement

### Description

Automatically apply a `10%` discount when the total price of items in the cart exceeds `$150`.

### Requirements

- Apply a bulk discount automatically when the cart subtotal exceeds `150`.
- The bulk discount percentage is `10%`.
- `getTotal()` should return the discounted total when the bulk discount is applicable.

### Example

Adding an item with a price of `200` should result in a discounted total of `180`.

```text
Subtotal: 200
Bulk discount: 10%
Final total: 180
```

### Bulk Discount Condition

```text
Subtotal > 150
      ↓
Apply 10% bulk discount
```

If the subtotal does not exceed `150`, the bulk discount should not be applied.

> [!note]  
> The requirement uses the word **exceeds**, which means the subtotal must be strictly greater than `150`. A subtotal of exactly `150` does not qualify for the bulk discount.

# Green Phase: Implement the Minimum Code

## Add Bulk Discount Constants

Add constants for the bulk discount threshold and percentage.

```java
private static final double BULK_DISCOUNT_THRESHOLD = 150;
private static final double BULK_DISCOUNT_PERCENTAGE = 10;
```

Using constants makes the discount rules easier to identify and avoids hardcoding the values directly inside `getTotal()`.

---

## Update `getTotal()`

First, calculate the cart subtotal.

```java
int subtotal = items.values()
        .stream()
        .mapToInt(item -> item.getPrice() * item.getQuantity())
        .sum();
```

Next, check whether the subtotal exceeds the bulk discount threshold.

```java
if (subtotal > BULK_DISCOUNT_THRESHOLD) {
    return (int) (subtotal * (1 - BULK_DISCOUNT_PERCENTAGE / 100));
}
```

If the subtotal does not qualify for the bulk discount, apply the existing percentage discount.

```java
return (int) (subtotal * (1 - percentageDiscount / 100));
```

The complete implementation is:

```java
public int getTotal() {
    int subtotal = items.values()
            .stream()
            .mapToInt(item -> item.getPrice() * item.getQuantity())
            .sum();

    if (subtotal > BULK_DISCOUNT_THRESHOLD) {
        return (int) (subtotal * (1 - BULK_DISCOUNT_PERCENTAGE / 100));
    }

    return (int) (subtotal * (1 - percentageDiscount / 100));
}
```

## Bulk Discount Calculation

For a subtotal of `200`:

```text
Bulk discount = 10%

Discounted total = 200 × (1 - 10 / 100)

Discounted total = 200 × 0.90

Discounted total = 180
```

## ShoppingCart.java

```java
import java.util.HashMap;
import java.util.Map;

import exceptions.ItemNotFoundException;

public class ShoppingCart {

    private Map<String, CartItem> items = new HashMap<>();

    private double percentageDiscount = 0.0;

    private static final double BULK_DISCOUNT_THRESHOLD = 150;
    private static final double BULK_DISCOUNT_PERCENTAGE = 10;

    public int getItemCount() {
        return items.values()
                .stream()
                .mapToInt(CartItem::getQuantity)
                .sum();
    }

    public int getTotal() {
        int subtotal = items.values()
                .stream()
                .mapToInt(item -> item.getPrice() * item.getQuantity())
                .sum();

        if (subtotal > BULK_DISCOUNT_THRESHOLD) {
            return (int) (subtotal * (1 - BULK_DISCOUNT_PERCENTAGE / 100));
        }

        return (int) (subtotal * (1 - percentageDiscount / 100));
    }

    public void addItem(Product product, int quantity) {
        items.put(product.getId(), new CartItem(product, quantity));
    }

    public void addItem(Product product) {
        addItem(product, 1);
    }

    public void removeItem(String id) {
        if (!items.containsKey(id)) {
            throw new ItemNotFoundException("Item not found");
        }

        CartItem item = items.get(id);

        if (item.getQuantity() > 1) {
            item.setQuantity(item.getQuantity() - 1);
        } else {
            items.remove(id);
        }
    }

    public void applyDiscount(double percentage) {
        this.percentageDiscount = percentage;
    }
}
```

# Key Takeaways

- The bulk discount is applied automatically based on the cart subtotal.
- The discount applies only when the subtotal is strictly greater than the threshold.
- `static final` constants are used to represent fixed business rules.
- `getTotal()` is responsible for determining whether the bulk discount applies.
- The test drives the implementation by defining the expected behavior before the bulk discount logic is added.

> [!important]  
> In the provided implementation, the bulk discount takes precedence over the manually applied `percentageDiscount`. If both discount mechanisms are intended to be combined, that behavior would need to be defined by an additional requirement and test.
