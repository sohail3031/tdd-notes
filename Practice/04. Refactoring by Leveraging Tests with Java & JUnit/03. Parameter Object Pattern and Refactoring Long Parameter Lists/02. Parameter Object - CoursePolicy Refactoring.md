# Objective

Refactor the `processExamScore()` method to use a **`CoursePolicy` parameter object**.

The following parameters are logically related because they define the rules and policies used when processing an exam:

```java
int bonusPointsPerActivity
double passingThreshold
double retakePenaltyPercentage
double missedHomeworkPenaltyPercentage
```

These parameters should be grouped into a single `CoursePolicy` object.

> [!important] Additional Requirement  
> `retakePenaltyPercentage` and `missedHomeworkPenaltyPercentage` were missing from the original implementation. They must be added as new fields to `CoursePolicy` and used instead of hard-coded magic numbers.

---

## Before Refactoring

The method currently has separate parameters for course policies:

```java
public ExamResult processExamScore(
    double examScore,
    boolean isHomeworkComplete,
    int attendanceScore,
    List<String> bonusActivities,
    ScoreWeights scoreWeights,
    int bonusPointsPerActivity,
    double passingThreshold,
    boolean isRetake,
    String courseCode
)
```

This means the method has to receive individual values such as:

```java
2,       // bonus points
75,      // passing threshold
```

And the implementation contains magic numbers:

```java
weightedScore *= 0.95;
```

and:

```java
double homeworkScore = isHomeworkComplete ? 100.0 : 60.0;
```

The `0.95` and `60.0` values represent business rules but are not explicitly named.

# Step 1: Create `CoursePolicy`

Create a new class to encapsulate all course-related policies.

### `CoursePolicy.java`

```java
public class CoursePolicy {

    private final int bonusPointsPerActivity;
    private final double passingThreshold;
    private final double retakePenaltyPercentage;
    private final double missedHomeworkPenaltyPercentage;

    public CoursePolicy(
        int bonusPointsPerActivity,
        double passingThreshold,
        double retakePenaltyPercentage,
        double missedHomeworkPenaltyPercentage
    ) {
        this.bonusPointsPerActivity = bonusPointsPerActivity;
        this.passingThreshold = passingThreshold;
        this.retakePenaltyPercentage = retakePenaltyPercentage;
        this.missedHomeworkPenaltyPercentage = missedHomeworkPenaltyPercentage;
    }

    public int getBonusPointsPerActivity() {
        return bonusPointsPerActivity;
    }

    public double getPassingThreshold() {
        return passingThreshold;
    }

    public double getRetakePenaltyPercentage() {
        return retakePenaltyPercentage;
    }

    public double getMissedHomeworkPenaltyPercentage() {
        return missedHomeworkPenaltyPercentage;
    }
}
```

### `CoursePolicy` now represents:

```text
CoursePolicy
├── bonusPointsPerActivity
├── passingThreshold
├── retakePenaltyPercentage
└── missedHomeworkPenaltyPercentage
```

These values all describe **course rules**, so grouping them together creates a cohesive object.

## Replace Magic Numbers

### Missed Homework

Previously:

```java
double homeworkScore =
    isHomeworkComplete ? 100.0 : 60.0;
```

The `60.0` implicitly means:

> Students receive 60% of the homework score when homework is incomplete.

Instead, calculate it from the policy:

```java
double homeworkScore = isHomeworkComplete
    ? 100.0
    : 100.0 * (1.0 - coursePolicy.getMissedHomeworkPenaltyPercentage());
```

With a 40% penalty:

```text
100 × (1 - 0.40)
= 60
```

So the existing behavior is preserved.

---

### Retake Penalty

Previously:

```java
if (isRetake) {
    weightedScore *= 0.95;
}
```

The `0.95` represents a 5% reduction.

Now:

```java
if (isRetake) {
    weightedScore *=
        (1.0 - coursePolicy.getRetakePenaltyPercentage());
}
```

With a 5% penalty:

```text
1.0 - 0.05
= 0.95
```

Again, the existing behavior is preserved while removing the magic number.

# Complete `ExamProcessor.java`

```java
import java.util.List;

public class ExamProcessor {

    public ExamResult processExamScore(
        double examScore,
        boolean isHomeworkComplete,
        int attendanceScore,
        List<String> bonusActivities,
        ScoreWeights scoreWeights,
        CoursePolicy coursePolicy,
        boolean isRetake,
        String courseCode
    ) {
        // Normalize input scores to handle edge cases
        double normalizedExamScore = clamp(examScore, 0, 100);
        double normalizedAttendanceScore = clamp(attendanceScore, 0, 3);

        // Calculate weighted exam score
        double weightedScore =
            normalizedExamScore * scoreWeights.getExam();

        // Calculate homework component
        // 100% if complete, reduced by the missed homework penalty if incomplete
        double homeworkScore = isHomeworkComplete
            ? 100.0
            : 100.0 * (1.0 -
                coursePolicy.getMissedHomeworkPenaltyPercentage());

        weightedScore +=
            homeworkScore * scoreWeights.getHomework();

        // Calculate attendance component
        // Convert 0-3 scale to percentage
        double normalizedAttendancePercentage =
            (normalizedAttendanceScore / 3.0) * 100.0;

        weightedScore +=
            normalizedAttendancePercentage *
            scoreWeights.getAttendance();

        // Add bonus points after weights are applied
        double bonusPoints =
            bonusActivities.size() *
            coursePolicy.getBonusPointsPerActivity();

        weightedScore += bonusPoints;

        // Apply retake penalty if applicable
        if (isRetake) {
            weightedScore *=
                (1.0 - coursePolicy.getRetakePenaltyPercentage());
        }

        // Ensure score doesn't exceed 100 even with bonus points
        weightedScore = Math.min(100.0, weightedScore);

        // Round to the nearest 0.5
        double finalScore =
            roundToNearestHalf(weightedScore);

        return new ExamResult(
            finalScore,
            finalScore >= coursePolicy.getPassingThreshold(),
            calculateGradeLevel(finalScore)
        );
    }

    private double clamp(double value, double min, double max) {
        return Math.max(min, Math.min(max, value));
    }

    private double roundToNearestHalf(double value) {
        return Math.round(value * 2.0) / 2.0;
    }

    private GradeLevel calculateGradeLevel(double score) {
        if (score >= 93) return GradeLevel.A;
        if (score >= 90) return GradeLevel.AMinus;
        if (score >= 87) return GradeLevel.BPlus;
        if (score >= 83) return GradeLevel.B;
        if (score >= 80) return GradeLevel.BMinus;
        if (score >= 77) return GradeLevel.CPlus;
        if (score >= 73) return GradeLevel.C;
        if (score >= 70) return GradeLevel.CMinus;
        if (score >= 60) return GradeLevel.D;
        return GradeLevel.F;
    }
}
```

## Default Course Policy

Most tests use the same policy, so it makes sense to define it once:

```java
private static final CoursePolicy DEFAULT_POLICY =
    new CoursePolicy(2, 75, 0.05, 0.40);
```

This represents:

|Policy|Value|Meaning|
|---|--:|---|
|`bonusPointsPerActivity`|`2`|2 bonus points per activity|
|`passingThreshold`|`75`|75 is required to pass|
|`retakePenaltyPercentage`|`0.05`|5% retake penalty|
|`missedHomeworkPenaltyPercentage`|`0.40`|40% homework penalty|

This also makes the tests easier to understand.

```java
@Test
public void testCalculatesFinalGradeWithAllFactors() {
    ExamProcessor examProcessor = new ExamProcessor();

    ScoreWeights weights =
        new ScoreWeights(0.7, 0.1, 0.1);

    List<String> bonusActivities =
        Arrays.asList("extra_credit", "participation");

    ExamResult result = examProcessor.processExamScore(
        85,

        3,
        bonusActivities,

        DEFAULT_POLICY,
        false,
        "MATH101"
    );

    assertEquals(83.5, result.getFinalScore());
    assertEquals(true, result.isPassed());
    assertEquals(GradeLevel.B, result.getGradeLevel());
}
```

# Key Takeaways

> [!important] Parameter Object  
> A Parameter Object groups several parameters that represent a cohesive concept and allows the method to work with that concept directly.

- `CoursePolicy` groups course-specific business rules.
- `ScoreWeights` groups score-weight configuration.
- The method has fewer individual parameters.
- The method signature becomes easier to understand.
- Business rules are given meaningful names.
- `0.95` retake multiplier is replaced by `retakePenaltyPercentage`.
- `60%` incomplete-homework score is derived from `missedHomeworkPenaltyPercentage`.
- Tests become easier to configure and read.
- The new fields also make the policy more flexible for different courses.
- Parameter Objects should be used when parameters have a **strong conceptual relationship**, not simply to hide a long parameter list.
