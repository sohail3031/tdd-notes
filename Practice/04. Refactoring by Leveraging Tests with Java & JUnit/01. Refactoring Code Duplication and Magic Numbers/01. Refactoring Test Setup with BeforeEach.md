The goal of this task is to improve the maintainability of the test code by identifying and refactoring duplicated code in `ShoppingCartTest.java`.

The `ShoppingCart` object is repeatedly created in the **Arrange** section of every test. This duplication makes the tests more verbose and harder to maintain.

The objective is to:

1. Identify the duplicated `ShoppingCart` creation in the **Arrange** blocks.
2. Extract the creation of the `ShoppingCart` object into a `setUp()` method using JUnit 5's `@BeforeEach` annotation.
3. Update all existing tests to remove the repeated `ShoppingCart` instantiation.
4. Ensure that every test starts with a **new `ShoppingCart` instance**.

---

## Problem: Duplicated Test Setup

Initially, every test creates its own `ShoppingCart` instance:

```java
@Test
public void testCalculatesTotalForSingleItem() {
    // Arrange
    ShoppingCart cart = new ShoppingCart();

    cart.addItem("book", 20, 1);

    // Act
    double total = cart.calculateTotal();

    // Assert
    assertEquals(20, total);
}
```

The same setup code appears repeatedly throughout the test class:

```java
ShoppingCart cart = new ShoppingCart();
```

This is unnecessary duplication.

---

## Refactoring with `@BeforeEach`

JUnit 5 provides the `@BeforeEach` annotation for setup code that should run **before every test method**.

We can create the `ShoppingCart` once as a class-level variable and initialize it inside a `setUp()` method.

```java
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;

public class ShoppingCartTest {

    ShoppingCart cart;

    @BeforeEach
    public void setUp() {
        cart = new ShoppingCart();
    }

    // Tests...
}
```

### How It Works

The `setUp()` method runs automatically before **each** test.

For example:

```text
setUp()
   ↓
testCalculatesTotalForSingleItem()

setUp()
   ↓
testCalculatesTotalForMultipleItems()

setUp()
   ↓
testAppliesBulkDiscountForFiveItems()

...
```

Therefore, every test receives a **fresh `ShoppingCart` instance**.

This prevents state from one test from affecting another test.

## Refactored Test Class

```java
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;

public class ShoppingCartTest {

    ShoppingCart cart;

    @BeforeEach
    public void setUp() {
        cart = new ShoppingCart();
    }

    @Test
    public void testCalculatesTotalForSingleItem() {
        // Arrange
        cart.addItem("book", 20, 1);

        // Act
        double total = cart.calculateTotal();

        // Assert
        assertEquals(20, total);
    }

    @Test
    public void testCalculatesTotalForMultipleItems() {
        // Arrange
        cart.addItem("book", 20, 1);
        cart.addItem("pen", 5, 1);

        // Act
        double total = cart.calculateTotal();

        // Assert
        assertEquals(25, total);
    }

    @Test
    public void testAppliesBulkDiscountForFiveItems() {
        // Arrange
        cart.addItem("notebook", 10, 5);

        // Act
        double total = cart.calculateTotal();

        // Assert
        assertEquals(45, total); // 10 * 5 * 0.9
    }

    @Test
    public void testAppliesBulkDiscountForSixItems() {
        // Arrange
        cart.addItem("notebook", 10, 6);

        // Act
        double total = cart.calculateTotal();

        // Assert
        assertEquals(54, total); // 10 * 6 * 0.9
    }

    @Test
    public void testAppliesBulkDiscountForTenItems() {
        // Arrange
        cart.addItem("notebook", 10, 10);

        // Act
        double total = cart.calculateTotal();

        // Assert
        assertEquals(90, total); // 10 * 10 * 0.9
    }

    @Test
    public void testDoesNotApplyBulkDiscountForFourItems() {
        // Arrange
        cart.addItem("notebook", 10, 4);

        // Act
        double total = cart.calculateTotal();

        // Assert
        assertEquals(40, total); // 10 * 4
    }

    @Test
    public void testAppliesStudentDiscountToTotalOfOneItem() {
        // Arrange
        cart.addItem("textbook", 100, 1);

        // Act
        double total = cart.calculateTotalWithStudentDiscount();

        // Assert
        assertEquals(85, total); // 100 * 0.85
    }

    @Test
    public void testAppliesStudentDiscountToTotalOfMultipleItems() {
        // Arrange
        cart.addItem("textbook", 100, 1);
        cart.addItem("notebook", 20, 1);

        // Act
        double total = cart.calculateTotalWithStudentDiscount();

        // Assert
        assertEquals(102, total); // (100 + 20) * 0.85
    }

    @Test
    public void testAppliesBothBulkAndStudentDiscount() {
        // Arrange
        cart.addItem("textbook", 100, 5);

        // Act
        double total = cart.calculateTotalWithStudentDiscount();

        // Assert
        assertEquals(382.50, total, 0.001); // (100 * 5 * 0.9) * 0.85
    }
}
```

## Key Concept: `@BeforeEach`

`@BeforeEach` is a JUnit 5 annotation used to execute a setup method **before every test method**.

```java
@BeforeEach
public void setUp() {
    cart = new ShoppingCart();
}
```

### Benefits

- Eliminates duplicated setup code.
- Makes individual tests shorter and easier to read.
- Ensures every test starts with a fresh object.
- Prevents tests from sharing state.
- Makes future changes to the test setup easier.

---

## AAA Pattern After Refactoring

The tests still follow the **Arrange–Act–Assert (AAA)** pattern.

### Arrange

Configure the test-specific data:

```java
cart.addItem("book", 20, 1);
```

### Act

Execute the method being tested:

```java
double total = cart.calculateTotal();
```

### Assert

Verify the expected result:

```java
assertEquals(20, total);
```

The creation of the `ShoppingCart` object is no longer part of every test's Arrange section because it is common setup handled by `@BeforeEach`.

---

## Important Takeaway

> Use `@BeforeEach` when multiple tests require the same initial setup.

Instead of repeating:

```java
ShoppingCart cart = new ShoppingCart();
```

in every test, move the common setup into:

```java
@BeforeEach
public void setUp() {
    cart = new ShoppingCart();
}
```

This is a simple **refactoring** that reduces duplication while keeping each test independent.

## Supporting Classes

### `ShoppingCart.java`

```java
import java.util.ArrayList;
import java.util.List;

public class ShoppingCart {

    private final List<CartItem> items = new ArrayList<>();

    public void addItem(String name, double price, int quantity) {
        items.add(new CartItem(name, price, quantity));
    }

    public double calculateTotal() {
        double total = 0;

        for (CartItem item : items) {
            double itemTotal = item.getPrice() * item.getQuantity();

            if (item.getQuantity() >= 5) {
                itemTotal *= 0.9; // 10% discount
            }

            total += itemTotal;
        }

        return total;
    }

    public double calculateTotalWithStudentDiscount() {
        double total = 0;

        for (CartItem item : items) {
            double itemTotal = item.getPrice() * item.getQuantity();

            if (item.getQuantity() >= 5) {
                itemTotal *= 0.9; // 10% discount
            }

            total += itemTotal;
        }

        return total * 0.85; // 15% student discount
    }
}
```

### `CartItem.java`

```java
public class CartItem {

    private final String name;
    private final double price;
    private final int quantity;

    public CartItem(String name, double price, int quantity) {
        this.name = name;
        this.price = price;
        this.quantity = quantity;
    }

    public String getName() {
        return name;
    }

    public double getPrice() {
        return price;
    }

    public int getQuantity() {
        return quantity;
    }
}
```
