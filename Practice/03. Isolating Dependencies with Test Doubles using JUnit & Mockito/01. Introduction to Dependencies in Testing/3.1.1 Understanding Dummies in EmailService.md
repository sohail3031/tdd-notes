## `EmailService` Dependencies

`EmailService` depends on two interfaces:

```java
private final ILogger logger;
private final IEmailSender emailSender;
```

These dependencies are passed through the constructor:

```java
public EmailService(ILogger logger, IEmailSender emailSender) {
    this.logger = logger;
    this.emailSender = emailSender;
}
```

This allows the test to provide dummy implementations instead of real services.

---

## Role of `DummyLogger`

```java
public class DummyLogger implements ILogger {

    @Override
    public void log(String message) {
        // Do nothing
    }
}
```

`DummyLogger` is a **Dummy test double**.

Its purpose is simply to satisfy the `ILogger` dependency required by `EmailService`.

Although `EmailService` calls:

```java
logger.log("Sending email to " + to);
```

the dummy does nothing.

### Why?

The test is focused on validating email parameters, **not testing an actual logging system**.

---

## Role of `DummyEmailSender`

```java
public class DummyEmailSender implements IEmailSender {

    @Override
    public void send(String to, String subject, String body) {
        // Do nothing
    }
}
```

`DummyEmailSender` is also a **Dummy test double**.

It satisfies the `IEmailSender` dependency without actually sending an email.

When valid parameters are provided:

```java
emailSender.send(to, subject, body);
```

is called, but no real email is sent.

This keeps the test:

- Fast
- Isolated
- Predictable
- Independent of an actual email server

## Test Setup

```java
@BeforeEach
public void setUp() {
    emailService = new EmailService(
        new DummyLogger(),
        new DummyEmailSender()
    );
}
```

Before every test, a new `EmailService` is created using the dummy dependencies.

```text
EmailServiceTest
       │
       ▼
  EmailService
   /          \
  ▼            ▼
DummyLogger  DummyEmailSender
   │            │
Does nothing  Does nothing
```

## What the Tests Validate

|Test|Expected Result|
|---|---|
|Valid email parameters|`true`|
|Invalid email address|`false`|
|Empty subject|`false`|
|Empty body|`false`|
|Body longer than 1000 characters|`false`|

The tests focus specifically on the validation logic inside:

```java
sendEmail()
```

They do **not** test real logging or real email delivery.
