# `ArgumentCaptor`

## What Is `ArgumentCaptor`?

Mockito's `ArgumentCaptor` allows us to **capture the arguments passed to a mocked or spied method**.

This is particularly useful when a method is called multiple times and we want to inspect the individual arguments passed during each invocation.

For example:

```java
ArgumentCaptor<Notification> notificationCaptor =
    ArgumentCaptor.forClass(Notification.class);
```

The captor can then be used with `verify()`:

```java
verify(senderSpy, times(3)).send(notificationCaptor.capture());
```

After the verification, the captured arguments can be retrieved:

```java
List<Notification> notifications = notificationCaptor.getAllValues();
```

The list contains the `Notification` objects passed to each invocation of `send()`.

---

# Why Use `ArgumentCaptor`?

Suppose `send()` is called three times:

```text
send(notification1)
send(notification2)
send(notification3)
```

Using `ArgumentCaptor`, we can capture all three arguments:

```text
notifications.get(0) → notification1
notifications.get(1) → notification2
notifications.get(2) → notification3
```

This allows us to verify the contents of each individual call.

# Important Difference: `argThat()` vs `ArgumentCaptor`

Both `argThat()` and `ArgumentCaptor` can be used to inspect method arguments, but they are useful in different situations.

|Feature|`argThat()`|`ArgumentCaptor`|
|---|---|---|
|Verify argument properties|Yes|Yes|
|Capture argument for later inspection|No|Yes|
|Inspect multiple calls individually|Less convenient|Yes|
|Verify call sequence|Less convenient|Yes|
|Useful for complex object inspection|Yes|Yes|

### `argThat()`

Use `argThat()` when you want to verify that a particular argument matches a condition:

```java
verify(senderSpy).send(argThat(notification ->
    notification.getPriority() == Priority.LOW
));
```

### `ArgumentCaptor`

Use `ArgumentCaptor` when you want to capture the arguments and inspect them afterward:

```java
verify(senderSpy, times(3)).send(notificationCaptor.capture());

List<Notification> notifications =
    notificationCaptor.getAllValues();
```

This is especially useful when the same method is called multiple times with different arguments.

# Key Takeaways

- **`ArgumentCaptor`** captures arguments passed to mocked or spied methods.
- `getAllValues()` returns all captured arguments as a list.
- The order of captured values corresponds to the order in which the method was invoked.
- `verify(senderSpy, times(3))` verifies that `send()` was called exactly three times.
- `ArgumentCaptor` is particularly useful when the same method is called multiple times with different arguments.
- `notifyMultipleUsers()` delegates the notification logic to `notifyUser()`, ensuring that the same priority rules are applied to every user.
- `notifyMultipleUsers()` sends notifications in the same order as the users appear in the input list.
