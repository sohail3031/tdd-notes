# Task Overview

In this task, the goal is to test the `calculateBulkPrices` method in the `PricingService` class using Mockito.

The objective is to ensure that bulk prices are calculated correctly for multiple amounts using a currency exchange rate.

Specifically, the implementation should:

1. Mock the `getRate` method of `IExchangeRateService` to return a fixed exchange rate of `1.5`.
2. Call `calculateBulkPrices` with a list of amounts: `[100, 200, 300]`.
3. Convert the amounts from `USD` to `EUR`.
4. Implement `calculateBulkPrices`, which does not initially exist.
5. Verify that `getRate` is called only once because the same exchange rate should be reused for all amounts.
6. Verify that the converted amounts are `[150.0, 300.0, 450.0]`.

---

# Key Learning Concepts

## Mocking a Dependency

The `IExchangeRateService` is an external dependency of `PricingService`.

Instead of calling a real exchange rate API during the test, Mockito creates a mock:

```java
@Mock
private IExchangeRateService mockExchangeRateService;
```

This allows the test to control the behavior of `getRate()`.

For example:

```java
when(mockExchangeRateService.getRate("USD", "EUR")).thenReturn(1.5);
```

Whenever the `PricingService` requests the exchange rate from `USD` to `EUR`, the mock returns `1.5`.

---

# Testing Bulk Price Conversion

The input prices are:

```text
[100, 200, 300]
```

The mocked exchange rate is:

```text
USD → EUR = 1.5
```

Therefore:

```text
100 × 1.5 = 150
200 × 1.5 = 300
300 × 1.5 = 450
```

Expected result:

```text
[150.0, 300.0, 450.0]
```

---

# Important Optimization

A key requirement of this task is that the exchange rate should be retrieved only once.

A less efficient implementation would call:

```java
exchangeRateService.getRate(fromCurrency, toCurrency);
```

for every price in the list.

For three prices, this would result in three calls.

Instead, the implementation should:

1. Retrieve the exchange rate once.
2. Store it in a variable.
3. Reuse the same rate for every price.

Example:

```java
double rate = exchangeRateService.getRate(fromCurrency, toCurrency);
```

Then use the same `rate` for every price:

```java
for (Integer price : prices) {
    double converted = price * rate;
}
```

This reduces unnecessary external service calls.

# Final Test Implementation

## `PricingServiceTest.java`

```java
import org.junit.jupiter.api.Test;
import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;
import org.junit.jupiter.api.extension.ExtendWith;

import java.util.List;

import static org.mockito.Mockito.*;
import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertThrows;

@ExtendWith(MockitoExtension.class)
public class PricingServiceTest {

    @Mock
    private IExchangeRateService mockExchangeRateService;

    @InjectMocks
    private PricingService pricingService;

    @Test
    public void testConvertPriceUsesExchangeRate() throws Exception {
        // Arrange
        when(mockExchangeRateService.getRate("USD", "EUR"))
                .thenReturn(1.5);

        // Act
        double result = pricingService.convertPrice(100, "USD", "EUR");

        // Assert
        verify(mockExchangeRateService, times(1))
                .getRate("USD", "EUR");

        assertEquals(150.00, result);
    }

    @Test
    public void testConvertPriceWithSameCurrenciesDoesNotCallGetRate()
            throws Exception {

        // Act
        double result = pricingService.convertPrice(100, "USD", "USD");

        // Assert
        verify(mockExchangeRateService, never())
                .getRate(anyString(), anyString());

        assertEquals(100.00, result);
    }

    @Test
    public void testConvertPriceThrowsExceptionForNegativeAmount()
            throws Exception {

        // Act & Assert
        Exception exception = assertThrows(
                IllegalArgumentException.class,
                () -> pricingService.convertPrice(-50, "USD", "EUR")
        );

        assertEquals(
                "Amount cannot be negative",
                exception.getMessage()
        );

        verify(mockExchangeRateService, never())
                .getRate(anyString(), anyString());
    }

    @Test
    public void testConvertPriceHandlesDifferentExchangeRates()
            throws Exception {

        // Arrange
        when(mockExchangeRateService.getRate(anyString(), anyString()))
                .thenAnswer(invocation -> {

                    String from = invocation.getArgument(0);
                    String to = invocation.getArgument(1);

                    if ("USD".equals(from) && "EUR".equals(to)) {
                        return 0.85;
                    }

                    if ("USD".equals(from) && "GBP".equals(to)) {
                        return 0.73;
                    }

                    return 1.0;
                });

        // Act
        double resultEUR =
                pricingService.convertPrice(100, "USD", "EUR");

        double resultGBP =
                pricingService.convertPrice(100, "USD", "GBP");

        // Assert
        assertEquals(85.00, resultEUR, 0.001);
        assertEquals(73.00, resultGBP, 0.001);

        verify(mockExchangeRateService, times(2))
                .getRate(anyString(), anyString());
    }

    @Test
    public void testCalculateBulkPricesUsesRateOnce()
            throws Exception {

        // Arrange
        when(mockExchangeRateService.getRate("USD", "EUR"))
                .thenReturn(1.5);

        List<Integer> inputPrices =
                List.of(100, 200, 300);

        // Act
        List<Double> result =
                pricingService.calculateBulkPrices(
                        inputPrices,
                        "USD",
                        "EUR"
                );

        // Assert

        // Verify that the exchange rate is fetched only once.
        verify(mockExchangeRateService, times(1))
                .getRate("USD", "EUR");

        List<Double> expectedPrices =
                List.of(150.00, 300.00, 450.00);

        assertEquals(expectedPrices, result);
    }
}
```

# Final `PricingService` Implementation

## `PricingService.java`

```java
import java.util.ArrayList;
import java.util.List;

public class PricingService {

    private final IExchangeRateService exchangeRateService;

    public PricingService(
            IExchangeRateService exchangeRateService
    ) {
        this.exchangeRateService = exchangeRateService;
    }

    public double convertPrice(
            double amount,
            String fromCurrency,
            String toCurrency
    ) throws Exception {

        // Validate the amount before making any external call.
        if (amount < 0) {
            throw new IllegalArgumentException(
                    "Amount cannot be negative"
            );
        }

        // Avoid unnecessary exchange rate lookups when both
        // currencies are the same.
        if (fromCurrency.equalsIgnoreCase(toCurrency)) {
            return Math.round(amount * 100.0) / 100.0;
        }

        double rate =
                exchangeRateService.getRate(
                        fromCurrency,
                        toCurrency
                );

        return Math.round(amount * rate * 100.0) / 100.0;
    }

    public List<Double> calculateBulkPrices(
            List<Integer> prices,
            String fromCurrency,
            String toCurrency
    ) throws Exception {

        List<Double> result = new ArrayList<>();

        // Return an empty result for null or empty input.
        if (prices == null || prices.isEmpty()) {
            return result;
        }

        boolean isSameCurrency =
                fromCurrency.equalsIgnoreCase(toCurrency);

        double rate = 1.0;

        // Fetch the exchange rate only once for the entire batch.
        if (!isSameCurrency) {
            rate = exchangeRateService.getRate(
                    fromCurrency,
                    toCurrency
            );
        }

        // Convert every price using the same exchange rate.
        for (Integer price : prices) {

            if (price < 0) {
                throw new IllegalArgumentException(
                        "Amount cannot be negative"
                );
            }

            double convertedPrice =
                    isSameCurrency
                            ? price
                            : price * rate;

            result.add(
                    Math.round(convertedPrice * 100.0) / 100.0
            );
        }

        return result;
    }
}
```

# Key Takeaways

## 1. Mock External Dependencies

Mockito allows us to test `PricingService` without using a real exchange rate API.

```java
@Mock
private IExchangeRateService mockExchangeRateService;
```

---

## 2. Control Mock Behavior

Use `when(...).thenReturn(...)` when a fixed response is required.

```java
when(mockExchangeRateService.getRate("USD", "EUR"))
        .thenReturn(1.5);
```

---

## 3. Use `thenAnswer()` for Dynamic Behavior

Use `thenAnswer()` when the return value depends on the method arguments.

```java
when(mockExchangeRateService.getRate(anyString(), anyString()))
        .thenAnswer(invocation -> {

            String to = invocation.getArgument(1);

            if ("EUR".equals(to)) {
                return 0.85;
            }

            if ("GBP".equals(to)) {
                return 0.73;
            }

            return 1.0;
        });
```

---

## 4. Verify Interactions

Mockito can verify not only the returned result but also how a dependency was used.

```java
verify(mockExchangeRateService, times(1))
        .getRate("USD", "EUR");
```

This is particularly useful when testing optimization and interaction behavior.

---

## 5. Avoid Unnecessary External Calls

When converting multiple prices using the same currency pair, retrieve the exchange rate once and reuse it.

```text
One exchange rate lookup
        ↓
Store the rate
        ↓
Reuse the rate for all prices
        ↓
Reduce unnecessary external calls
```

## Final Concept Summary

> **Mocks allow us to isolate dependencies, control their behavior, and verify interactions. In addition to checking output values, Mockito tests can verify how many times a dependency was called and with which arguments.**

This task demonstrates an important testing principle: **correctness is not only about producing the right result—it can also include ensuring that dependencies are used efficiently and correctly.**
