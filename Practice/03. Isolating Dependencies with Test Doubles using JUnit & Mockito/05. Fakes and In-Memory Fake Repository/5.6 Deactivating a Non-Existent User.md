# Task

In this final practice task, we use **Test-Driven Development (TDD)** to handle the scenario where an attempt is made to deactivate a user who does not exist.

The goal is to ensure that the `UserService`:

1. Checks whether the user exists before completing the deactivation.    
2. Throws an appropriate exception when the user does not exist.
3. Uses the message:

```text
User not found
```

This exercise reinforces how tests can be used to define expected application behavior and guide the implementation.

---

# Requirements

The `deactivateUser` method should behave as follows:

|Scenario|Expected Behavior|
|---|---|
|User exists|Remove the user and return `true`|
|User does not exist|Throw an exception with the message `"User not found"`|

---

# TDD Approach

## 🔴 Red — Write the Failing Test

First, write a test for attempting to deactivate a user with an ID that does not exist.

The test should verify:

- An `IllegalArgumentException` is thrown.
- The exception message is `"User not found"`.

```java
@Test
public void testDeactivateUserThrowsExceptionForNonExistentUser() {

    // Act & Assert
    Exception exception = assertThrows(
            IllegalArgumentException.class,
            () -> userService.deactivateUser("999")
    );

    assertEquals("User not found", exception.getMessage());
}
```

Initially, this test fails because the original implementation simply returns the result of `repository.delete(id)`.

```java
public boolean deactivateUser(String id) {
    return repository.delete(id);
}
```

When the user does not exist, `repository.delete(id)` returns `false`, but the test expects an exception.

---

# 🟢 Green — Implement the Minimum Code

The repository's `delete()` method returns:

- `true` when a user is successfully removed.
- `false` when no user exists with the given ID.

The implementation can use this result to determine whether an exception should be thrown.

```java
public boolean deactivateUser(String id) throws Exception {
    boolean result = repository.delete(id);

    if (result) {
        return true;
    }

    throw new IllegalArgumentException("User not found");
}
```

Now the test passes.

# Final Test

## `UserServiceTest.java`

```java
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.*;

import java.util.List;

public class UserServiceTest {

    private InMemoryUserRepository userRepository;
    private UserService userService;

    @BeforeEach
    public void setUp() {
        userRepository = new InMemoryUserRepository();
        userService = new UserService(userRepository);
    }

    @Test
    public void testRegisterUserCreatesNewUserSuccessfully() throws Exception {

        // Act
        User user = userService.registerUser(
                "test@example.com",
                "Test User"
        );

        // Assert
        assertEquals("test@example.com", user.getEmail());
        assertEquals("Test User", user.getName());
        assertNotNull(user.getId());
        assertNotNull(user.getCreatedAt());

        List<User> repositoryUsers = userRepository.findAll();

        assertEquals(1, repositoryUsers.size());
        assertEquals("Test User", repositoryUsers.get(0).getName());
    }

    @Test
    public void testRegisterUserWithDuplicateEmailThrowsException()
            throws Exception {

        // Arrange
        String duplicateEmail = "test@example.com";

        userService.registerUser(
                duplicateEmail,
                "First User"
        );

        // Act & Assert
        Exception exception = assertThrows(
                Exception.class,
                () -> userService.registerUser(
                        duplicateEmail,
                        "Second User"
                )
        );

        assertEquals(
                "User with this email already exists",
                exception.getMessage()
        );
    }

    @Test
    public void testUpdateUserNameUpdatesUserSuccessfully()
            throws Exception {

        // Arrange
        User user = userService.registerUser(
                "test@example.com",
                "Old Name"
        );

        String userId = user.getId();

        // Act
        userService.updateUserName(
                userId,
                "New Name"
        );

        // Assert
        User updatedUser =
                userRepository.findById(userId);

        assertNotNull(updatedUser);
        assertEquals("New Name", updatedUser.getName());
        assertEquals("test@example.com", updatedUser.getEmail());

        assertEquals(
                user.getCreatedAt(),
                updatedUser.getCreatedAt()
        );
    }

    @Test
    public void testDeactivateUserRemovesUserSuccessfully()
            throws Exception {

        // Arrange
        User user = userService.registerUser(
                "test@example.com",
                "Test User"
        );

        String userId = user.getId();

        // Act
        boolean result =
                userService.deactivateUser(userId);

        // Assert
        assertTrue(result);
        assertNull(userRepository.findById(userId));
    }

    @Test
    public void testDeactivateUserThrowsExceptionForNonExistentUser() {

        // Act & Assert
        Exception exception = assertThrows(
                IllegalArgumentException.class,
                () -> userService.deactivateUser("999")
        );

        assertEquals(
                "User not found",
                exception.getMessage()
        );
    }
}
```

# Final Implementation

## `UserService.java`

```java
public class UserService {

    private final IUserRepository repository;

    public UserService(IUserRepository repository) {
        this.repository = repository;
    }

    public User registerUser(String email, String name)
            throws Exception {

        User existingUser = repository.findByEmail(email);

        if (existingUser != null) {
            throw new Exception(
                    "User with this email already exists"
            );
        }

        return repository.create(
                new User(email, name)
        );
    }

    public User updateUserName(String id, String newName) {
        return repository.update(
                id,
                new User(null, null, newName, null)
        );
    }

    public boolean deactivateUser(String id) throws Exception {

        boolean result = repository.delete(id);

        if (result) {
            return true;
        }

        throw new IllegalArgumentException("User not found");
    }
}
```

# Understanding `repository.delete()`

The fake repository implements deletion as follows:

```java
@Override
public boolean delete(String id) {
    return users.remove(id) != null;
}
```

## When the User Exists

```text
users.remove(id)
        ↓
Returns the removed User
        ↓
Result is not null
        ↓
Returns true
```

## When the User Does Not Exist

```text
users.remove(id)
        ↓
Returns null
        ↓
Result is null
        ↓
Returns false
```

The `UserService` converts this `false` result into a meaningful exception.

# AAA Pattern

## Arrange

No user is created because the purpose of the test is to verify behavior when the user does not exist.

## Act

Attempt to deactivate a non-existent user.

```java
userService.deactivateUser("999");
```

## Assert

Verify that the correct exception and message are produced.

```java
Exception exception = assertThrows(
        IllegalArgumentException.class,
        () -> userService.deactivateUser("999")
);
```

```java
    return true;
}
```

---

## 🔵 Refactor

The implementation can be simplified slightly without changing its behavior.

A cleaner version is:

```java
public boolean deactivateUser(String id) {
    if (!repository.delete(id)) {
        throw new IllegalArgumentException("User not found");
    }

    return true;
}
```

This version avoids the temporary `result` variable and makes the failure condition explicit.

---

# Key Takeaways

- Tests can define how the application should behave in edge cases.
- `assertThrows()` is used to verify expected exceptions.
- Exception messages can be verified using `exception.getMessage()`.
- The fake repository returns `false` when deletion fails.
- The service layer can convert low-level repository behavior into meaningful business behavior.
- Attempting to deactivate a non-existent user should not silently fail if the application's requirements specify an error.
- TDD helps identify and implement edge cases before they become production issues.
- A Fake test double allows this behavior to be tested without using a real database.

