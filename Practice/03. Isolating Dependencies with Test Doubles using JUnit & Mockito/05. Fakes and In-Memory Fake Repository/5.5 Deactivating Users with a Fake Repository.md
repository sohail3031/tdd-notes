# Task

In this task, we implement the `deactivateUser` method in the `UserService` class.

The goal is to ensure that when a user is deactivated, they are removed from the `UserRepository`.

Following the **Test-Driven Development (TDD)** approach, we first write a test that defines the expected behavior and then implement the minimum functionality required to make the test pass.

---

# Requirements

The `deactivateUser` method should:

1. Remove an existing user from the repository.    
2. Return `true` when the user is successfully removed.
3. Ensure that the removed user can no longer be found using `findById()`.

---

# Supporting Repository Functionality

## `IUserRepository.java`

The repository interface provides a `delete()` method that returns a `boolean`.

```java
import java.util.List;

public interface IUserRepository {

    User create(User user);

    User findById(String id);

    User findByEmail(String email);

    User update(String id, User user);

    boolean delete(String id);

    List<User> findAll();
}
```

The important method for this task is:

```java
boolean delete(String id);
```

The method should return:

- `true` if the user was successfully removed.
- `false` if no user with the given ID existed.

---

# `InMemoryUserRepository`

The `InMemoryUserRepository` acts as a **Fake test double**.

Instead of using a real database, it stores users in a `ConcurrentHashMap`.

The `delete()` method is:

```java
@Override
public boolean delete(String id) {
    return users.remove(id) != null;
}
```

## How It Works

`users.remove(id)`:

- Removes the user associated with the specified ID.
- Returns the removed user if one existed.
- Returns `null` if no user existed.

Therefore:

```java
users.remove(id) != null
```

returns:

```text
true  → User existed and was successfully removed
false → User did not exist
```

# TDD Implementation

## 1. Red — Write the Test

First, register a user in the fake repository.

Then, deactivate the user using their ID.

Finally, verify that:

- `deactivateUser()` returns `true`.
- The user no longer exists in the repository.

```java
@Test
public void testDeactivateUserRemovesUserSuccessfully() throws Exception {

    // Arrange
    User user = userService.registerUser(
            "test@example.com",
            "Test User"
    );

    // Act
    boolean deactivated = userService.deactivateUser(user.getId());

    User foundUser = userRepository.findById(user.getId());

    // Assert
    assertTrue(deactivated);
    assertNull(foundUser);
}
```

Before implementing `deactivateUser()`, this test cannot pass.

This is the **Red** phase of TDD.

---

# 2. Green — Implement the Minimum Code

The repository already provides the required deletion functionality.

Therefore, `UserService` only needs to delegate the operation to the repository.

```java
public boolean deactivateUser(String id) {
    return repository.delete(id);
}
```

The flow is:

```text
deactivateUser(id)
        ↓
repository.delete(id)
        ↓
Remove user from repository
        ↓
Return true or false
```

This implementation is sufficient to make the test pass.

This is the **Green** phase.

# Final Test

## `UserServiceTest.java`

```java
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.*;

import java.util.List;

public class UserServiceTest {

    private InMemoryUserRepository userRepository;
    private UserService userService;

    @BeforeEach
    public void setUp() {
        userRepository = new InMemoryUserRepository();
        userService = new UserService(userRepository);
    }

    @Test
    public void testRegisterUserCreatesNewUserSuccessfully() throws Exception {

        // Act
        User user = userService.registerUser(
                "test@example.com",
                "Test User"
        );

        // Assert
        assertEquals("test@example.com", user.getEmail());
        assertEquals("Test User", user.getName());
        assertNotNull(user.getId());
        assertNotNull(user.getCreatedAt());

        List<User> repositoryUsers = userRepository.findAll();

        assertEquals(1, repositoryUsers.size());
        assertEquals("Test User", repositoryUsers.get(0).getName());
    }

    @Test
    public void testRegisterUserWithDuplicateEmailThrowsException() throws Exception {

        // Arrange
        String duplicateEmail = "test@example.com";

        userService.registerUser(
                duplicateEmail,
                "First User"
        );

        // Act & Assert
        Exception exception = assertThrows(Exception.class, () -> {
            userService.registerUser(
                    duplicateEmail,
                    "Second User"
            );
        });

        assertEquals(
                "User with this email already exists",
                exception.getMessage()
        );
    }

    @Test
    public void testUpdateUserNameUpdatesUserSuccessfully() throws Exception {

        // Arrange
        User user = userService.registerUser(
                "test@example.com",
                "Old Name"
        );

        String userId = user.getId();

        // Act
        userService.updateUserName(
                userId,
                "New Name"
        );

        // Assert
        User updatedUser = userRepository.findById(userId);

        assertNotNull(updatedUser);
        assertEquals("New Name", updatedUser.getName());
        assertEquals("test@example.com", updatedUser.getEmail());
        assertEquals(
                user.getCreatedAt(),
                updatedUser.getCreatedAt()
        );
    }

    @Test
    public void testDeactivateUserRemovesUserSuccessfully() throws Exception {

        // Arrange
        User user = userService.registerUser(
                "test@example.com",
                "Test User"
        );

        // Act
        boolean deactivated =
                userService.deactivateUser(user.getId());

        User foundUser =
                userRepository.findById(user.getId());

        // Assert
        assertTrue(deactivated);
        assertNull(foundUser);
    }
}
```

# Final Implementation

## `UserService.java`

```java
public class UserService {

    private final IUserRepository repository;

    public UserService(IUserRepository repository) {
        this.repository = repository;
    }

    public User registerUser(String email, String name)
            throws Exception {

        User existingUser =
                repository.findByEmail(email);

        if (existingUser != null) {
            throw new Exception(
                    "User with this email already exists"
            );
        }

        return repository.create(
                new User(email, name)
        );
    }

    public User updateUserName(
            String id,
            String newName
    ) {
        return repository.update(
                id,
                new User(null, null, newName, null)
        );
    }

    public boolean deactivateUser(String id) {
        return repository.delete(id);
    }
}
```

# AAA Pattern

## Arrange

Create a user that can later be deactivated.

```java
User user = userService.registerUser(
        "test@example.com",
        "Test User"
);
```

## Act

Deactivate the user and retrieve the user from the repository.

```java
boolean deactivated =
        userService.deactivateUser(user.getId());

User foundUser =
        userRepository.findById(user.getId());
```

## Assert

Verify that the operation succeeded and that the user no longer exists.

```java
assertTrue(deactivated);
assertNull(foundUser);
```

---

# Why Use `assertTrue()`?

The original implementation used:

```java
assertEquals(deactivateUser, true);
```

A more readable assertion is:

```java
assertTrue(deactivated);
```

`assertTrue()` clearly communicates that the expected result is `true`.

# Key Takeaways

- The `deactivateUser()` method delegates deletion to the repository.
- The repository's `delete()` method returns whether the deletion was successful.
- `InMemoryUserRepository` acts as a **Fake** for a real database.
- A successful deactivation removes the user from the repository.
- After deactivation, `findById()` should return `null`.
- `assertTrue()` is clearer than `assertEquals(value, true)` when testing boolean values.
- The test verifies both:
    - The return value of the operation.
    - The resulting state of the repository.

# Important Pattern

When a service method simply delegates an operation to a repository, the implementation can remain concise:

```java
public boolean deactivateUser(String id) {
    return repository.delete(id);
}
```

The test should still verify both the **return value** and the **resulting system state**.
