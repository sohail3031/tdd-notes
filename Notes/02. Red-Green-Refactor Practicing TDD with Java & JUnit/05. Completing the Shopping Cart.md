# Overview

This is the **fifth and final unit** of the course, focused on practicing **Test Driven Development (TDD)** using **Java** and **JUnit**.

In this unit, the `ShoppingCart` system is extended with more advanced features involving:

- Quantity limits    
- Retrieving item details
- Discount codes
- Invalid discount codes
- Adding existing items
- Enforcing quantity limits when adding to existing items

Unlike previous units, the requirements provide descriptions rather than complete tests. The goal is to **define the tests and implement the code** required to make those tests pass.

This unit continues to follow the **Red-Green-Refactor** cycle:

1. **Red:** Write a failing test based on the requirement.
2. **Green:** Implement the minimum code required to make the test pass.
3. **Refactor:** Improve the implementation while keeping all tests passing.

# Requirement #11: Quantity Limit for a Single Item

## Description

The cart should enforce a maximum quantity of **10** for a single type of item.

Adding more than `10` units of the same item should not be allowed.

## Requirements

- Use `addItem(item, quantity)` to add items.
- Enforce a maximum quantity of `10` for a single item.
- Throw an `InvalidCartOperationException` when the limit is exceeded.
- The exception message should be `"Maximum quantity exceeded"`.

## Example

Attempting to add `11` units should result in:

```text
Add 11 units
      ↓
Quantity exceeds maximum of 10
      ↓
InvalidCartOperationException
      ↓
"Maximum quantity exceeded"
```

# Requirement #12: Retrieving Item Details by ID

## Description

When an item is added to the cart, its details should be retrievable using its ID.

The returned item should contain both the product information and its current quantity.

## Requirements

- Allow items to be added with a specific ID.
- Implement `getItem(id)`.
- Return the correct item details.
- Include:
    - ID
    - Name
    - Price
    - Quantity

## Example

Adding a product:

```text
ID = 1
Name = Book
Price = 10
Quantity = 1
```

Retrieving the item using ID `1` should return the corresponding product details and quantity.

# Requirement #13: Applying Discount Codes

## Description

The cart should support discount codes that reduce the total price by a specified percentage.

## Requirements

- Implement `applyDiscountCode(code)`.
- Support valid discount codes.
- The `HOLIDAY25` code should provide a **25% discount**.
- `getTotal()` should reflect the discounted price.

## Example

For a `Book` costing `100`:

```text
Original total = 100

Apply "HOLIDAY25"
        ↓
25% discount
        ↓
Discount = 25

Final total = 75
```

# Requirement #14: Invalid Discount Code

## Description

The cart should reject invalid discount codes.

## Requirements

- `applyDiscountCode(code)` should validate the supplied code.
- Invalid codes should throw an appropriate exception.
- The exception message should be `"Invalid discount code"`.

## Example

```text
Add item
    ↓
Apply "INVALID"
    ↓
Invalid discount code
    ↓
Exception is thrown
```

# Requirement #15: Adding an Existing Item

## Description

When an item that already exists in the cart is added again, its quantity should increase instead of creating a duplicate item.

The total price should reflect the cumulative quantity.

## Requirements

- Allow an existing item to be added again using `addItem()`.
- Increase the existing item's quantity.
- Do not create a duplicate cart entry.
- Ensure `getItem(id)` returns the updated quantity.
- Ensure `getTotal()` reflects the cumulative quantity.

## Example

Adding a `Book` with a price of `200` twice:

```text
First addition:
Quantity = 1
Price = 200

        ↓

Second addition:
Quantity = 1
Price = 200

        ↓

Final quantity = 2
Final total = 400
```

# Requirement #16: Adding to an Existing Item Respects Maximum Quantity

## Description

When additional units are added to an item that already exists in the cart, the **combined quantity** must not exceed the maximum limit of `10`.

## Requirements

- Allow additional quantities to be added to an existing item.
- Calculate the cumulative quantity.
- Enforce the maximum quantity of `10`.
- Throw an `InvalidCartOperationException` if the combined quantity exceeds `10`.
- The exception message should be `"Maximum quantity exceeded"`.

## Example

If the cart already contains `8` Books and `3` more are added:

```text
Existing quantity = 8
Additional quantity = 3

8 + 3 = 11
```

Since `11` exceeds the maximum allowed quantity of `10`:

```text
InvalidCartOperationException
"Maximum quantity exceeded"
```

# TDD Workflow

Each requirement should follow the same TDD process:

```text
Requirement
     ↓
Write Test
     ↓
RED
Test fails
     ↓
Implement Minimum Code
     ↓
GREEN
Test passes
     ↓
REFACTOR
Improve implementation
     ↓
All Tests Pass
```

## Key Takeaways

- Convert each requirement into a **focused test**.
- Write the test before implementing the feature.
- Implement only the **minimum code required** to make the test pass.
- Preserve existing behavior while adding new functionality.
- Use exceptions to handle invalid operations.
- Apply the **Red-Green-Refactor** cycle consistently.
- The final requirements combine **item management, quantity validation, exception handling, and discount functionality**.
