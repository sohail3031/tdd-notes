# Requirement

Adding multiple distinct products to the shopping cart should:

- Increase the item count to reflect the number of products added.
- Calculate the total price as the sum of the prices of all products in the cart.

### Example

Adding:

|ID|Name|Price|
|---|---|--:|
|`1`|Book|10|
|`2`|Pen|5|

should result in:

```text
Item count = 2
Total = 15
```

---

## TDD Cycle

### 🔴 Red — Write the Test

The existing implementation of `getTotal()` only returns the price of the first item. Therefore, we first write a test that exposes this limitation.

```java
@Test
public void testForAddingMultipleDistinctItems() {
    // Arrange
    Product book = new Product("1", "Book", 10);
    Product pen = new Product("2", "Pen", 5);

    // Act
    cart.addItem(book);
    cart.addItem(pen);

    int itemCount = cart.getItemCount();
    int total = cart.getTotal();

    // Assert
    assertEquals(2, itemCount);
    assertEquals(15, total);
}
```

The test should fail because the current `getTotal()` implementation only considers the first product:

```java
return items.get(0).getPrice();
```

For the two products, this returns `10` instead of the expected `15`.

This failure gives us a clear target for the implementation.

---

### 🟢 Green — Make the Test Pass

We only need to change `getTotal()` so that it calculates the sum of all product prices.

```java
public int getTotal() {
    if (items.size() == 0) {
        return 0;
    }

    return items.stream()
            .mapToInt(Product::getPrice)
            .sum();
}
```

The complete implementation is:

```java
import java.util.ArrayList;
import java.util.List;

public class ShoppingCart {

    private List<Product> items = new ArrayList<>();

    public int getItemCount() {
        return items.size();
    }

    public int getTotal() {
        if (items.size() == 0) {
            return 0;
        }

        return items.stream()
                .mapToInt(Product::getPrice)
                .sum();
    }

    public void addItem(Product product) {
        items.add(product);
    }
}
```

### How It Works

The stream:

```java
items.stream()
```

creates a stream containing all products.

Then:

```java
.mapToInt(Product::getPrice)
```

extracts the price of each product.

Finally:

```java
.sum()
```

adds all the prices together.

For example:

```text
Book → 10
Pen  → 5
-----------
Total → 15
```

The new test should now pass.

---

### 🔵 Refactor

The current implementation works, but this check is unnecessary:

```java
if (items.size() == 0) {
    return 0;
}
```

`sum()` already returns `0` when the stream contains no elements.

Therefore, we can simplify `getTotal()`:

```java
public int getTotal() {
    return items.stream()
            .mapToInt(Product::getPrice)
            .sum();
}
```

The refactored `ShoppingCart` is:

```java
import java.util.ArrayList;
import java.util.List;

public class ShoppingCart {

    private final List<Product> items = new ArrayList<>();

    public int getItemCount() {
        return items.size();
    }

    public int getTotal() {
        return items.stream()
                .mapToInt(Product::getPrice)
                .sum();
    }

    public void addItem(Product product) {
        items.add(product);
    }
}
```

Making `items` `final` also communicates that the list reference itself should not be reassigned.

## Final Test

A clean version of the test following the **Arrange-Act-Assert (AAA)** pattern is:

```java
@Test
public void testForAddingMultipleDistinctItems() {
    // Arrange
    Product book = new Product("1", "Book", 10);
    Product pen = new Product("2", "Pen", 5);

    // Act
    cart.addItem(book);
    cart.addItem(pen);

    int itemCount = cart.getItemCount();
    int total = cart.getTotal();

    // Assert
    assertEquals(2, itemCount);
    assertEquals(15, total);
}
```

## Key Takeaways

- A test can expose a limitation in an existing implementation.
- The **Red** phase identifies the missing behavior.
- The **Green** phase implements only what is necessary to satisfy the new test.
- Java Streams can conveniently aggregate values from a collection.
- `mapToInt(Product::getPrice).sum()` calculates the total price of all products.
- `sum()` naturally returns `0` for an empty stream, so an explicit empty-list check is unnecessary.
- Refactoring should preserve existing behavior while improving code quality.
